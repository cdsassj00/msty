## 왜 백업이 필요한가

Msty Studio는 데이터를 서버가 아니라 내 쪽에 저장합니다. 이것은 장점이면서 책임이기도 합니다. Msty 서버에 사본이 없으므로, 내 쪽 데이터가 사라지면 되찾아 줄 곳이 없습니다.

공식 문서의 Data Backups 항목은 특히 브라우저에 대해 경고합니다. Msty Studio는 데이터를 브라우저에 로컬로 저장하므로, 브라우저 캐시나 브라우저 데이터를 지우면 Msty 데이터가 삭제됩니다. Studio Web을 쓰는 사람이 "인터넷 사용 기록 삭제"를 눌렀다가 대화를 모두 잃을 수 있다는 뜻입니다.

문서의 권고는 정기적으로 백업하고 필요할 때 복원하라는 것입니다. 공식 Q&A도 정기 백업을 권합니다.

## 백업하기

### 알림에 따라

Msty는 주기적으로 백업하라는 알림을 띄웁니다. 알림 주기는 설정에서 바꿀 수 있습니다.

### 직접

1. **Settings**를 엽니다.
2. **Export Data**를 누릅니다.
3. Zip 파일이 만들어지면 내 컴퓨터에 저장합니다.

문서는 이 Zip 파일에 "모든 데이터"가 들어 있다고 설명합니다. 무엇이 들어가고 빠지는지의 상세 목록이나 Zip 안의 구조는 문서에 적혀 있지 않습니다. 내려받은 모델 파일처럼 용량이 큰 것이 포함되는지도 문서에 설명이 없으므로, 중요한 항목은 복원 시험으로 직접 확인하는 것이 가장 확실합니다.

### 백업 파일 보관

백업 파일에는 대화와 설정이 들어 있습니다. 다음을 권합니다.

- 컴퓨터 본체와 다른 곳(외장 디스크, 회사가 허용한 저장소)에 둡니다.
- 파일 이름에 날짜를 넣습니다. 예: `msty-backup-2026-10-11.zip`
- 업무 대화가 들어 있다면 회사의 자료 보관 규정을 따릅니다.

## 복원하기

1. **Settings**의 **Restore Data** 부분으로 갑니다.
2. Zip 파일을 끌어다 놓습니다.
3. **Restore Data**를 누릅니다.

가장 중요한 주의점은 이것입니다. 복원은 지금 있는 데이터를 모두 바꿉니다. 백업 이후에 나눈 대화는 복원하면 사라집니다. 그래서 문서는 가능하면 복원하기 전에 먼저 백업하라고 권합니다.

안전한 순서는 다음과 같습니다.

1. 현재 상태를 **Export Data**로 백업합니다.
2. 옛 백업 파일로 복원합니다.
3. 문제가 있으면 1번에서 만든 파일로 다시 복원합니다.

## 전체 삭제

**Settings**의 **Clear Data**를 누르면 모든 데이터가 삭제됩니다. 되돌릴 수 없습니다. 문서는 삭제 전에 백업하라고 적었습니다.

컴퓨터를 다른 사람에게 넘기거나 공용 PC에서 쓰던 흔적을 지울 때 쓰는 기능입니다.

## 새 컴퓨터로 옮기기

기기 사이에 자동 동기화가 없으므로 옮길 때는 직접 해야 합니다.

1. 옛 컴퓨터에서 **Export Data**로 Zip 파일을 만듭니다.
2. 파일을 새 컴퓨터로 옮깁니다.
3. 새 컴퓨터에 Studio를 설치합니다. [Windows 설치](/guide/install-windows/), [Mac 설치](/guide/install-mac/) 참고.
4. **Restore Data**로 복원합니다.

작업 공간 하나만 옮기려면 작업 공간 내보내기가 더 간단합니다. [작업 공간 만들고 옮기기](/guide/workspace-basics/)를 보세요.

## Lost & Found란

Lost & Found는 목록에서 사라진 작업 공간을 찾아 주는 기능입니다. Studio Desktop과 Studio Web 모두에 있습니다.

문서가 설명하는 원인은 이렇습니다. 웹 버전은 개인정보 보호와 호환성을 위해 데이터를 브라우저의 OPFS 데이터베이스에 로컬로 저장합니다. 그런데 가끔 브라우저가 예상치 못하게 새 데이터베이스를 만들고, 그러면 예전 작업 공간이 앱에 나타나지 않게 됩니다. 데이터가 지워진 것이 아니라 연결이 끊긴 상태입니다. Lost & Found는 이런 작업 공간을 찾아 다시 가져오게 해 줍니다.

## Lost & Found 쓰는 방법

### 1. 열기

**Settings > Data > Lost & Found**로 갑니다.

### 2. 검색하기

| 버전 | 선택지 | 하는 일 |
|---|---|---|
| Desktop | **Scan App Data** | 앱 내부 데이터 폴더를 뒤집니다 |
| Desktop | **Scan Folder** | 고른 폴더와 그 하위 폴더 전체를 뒤집니다 |
| Web | **Scan Folder** | 브라우저의 폴더 선택 창으로 폴더를 고릅니다 |

### 3. 결과 보기

검색은 작업 공간처럼 생긴 SQLite 데이터베이스를 찾아 표로 보여 줍니다. 파일마다 다음이 나옵니다.

- 작업 공간 이름
- 파일 이름, 크기, 마지막 수정 시각
- 상태
- 할 수 있는 동작

상태는 세 가지입니다.

| 상태 | 뜻 |
|---|---|
| **Current** | 지금 쓰고 있는 작업 공간과 일치 |
| **Linked** | 목록에 이미 있는 작업 공간과 일치 |
| **Found** | 현재 작업 공간 목록에 없음 |

되찾으려는 것은 대개 **Found** 상태의 항목입니다. 수정 시각과 크기를 보고 어느 것이 찾던 작업 공간인지 가늠합니다.

문서는 실제 Msty Studio 작업 공간 데이터베이스만 표에 나오며, 이 기능이 앱의 저장소나 사용자가 직접 고른 폴더 밖의 파일은 읽지 않는다고 밝힙니다.

## 작업 공간 되살리기

### 새 작업 공간으로 가져오기

1. 해당 줄의 **Actions** 메뉴를 엽니다.
2. **Import as new workspace**를 고릅니다.

되찾은 데이터가 담긴 새 작업 공간이 만들어집니다. 모든 상태에서 쓸 수 있고, 기존 데이터를 건드리지 않으므로 가장 안전한 방법입니다.

### 현재 작업 공간 복원하기

1. **Current**라고 표시된 줄을 찾습니다.
2. **Actions** 메뉴를 엽니다.
3. **Restore current workspace**를 고릅니다.
4. 경고 창에서 확인합니다.

지금 쓰는 작업 공간이 되찾은 데이터로 바뀝니다. **Current** 상태에서만 쓸 수 있습니다. 현재 내용을 덮어쓰므로, 확신이 없으면 **Import as new workspace**를 먼저 써서 내용을 확인하세요.

## 웹 버전: 브라우저 저장소 뒤지기

Studio Web에서는 한 단계가 더 필요합니다. Lost & Found는 브라우저의 원래 `File System` 폴더를 직접 검색할 수 없습니다. 보호된 시스템 위치에 있기 때문입니다. 그래서 접근할 수 있는 곳에 사본을 만들어야 합니다.

1. 쓰는 브라우저가 `File System` 데이터를 어디에 저장하는지 찾습니다. 브라우저와 운영체제에 따라 다르므로 검색해서 확인합니다.
2. `File System` 폴더를 찾습니다.
3. 폴더 전체를 **Desktop**이나 **Documents**처럼 단순하고 접근하기 쉬운 곳에 복사합니다. `C:\` 같은 시스템 최상위에는 두지 않습니다.
4. **Lost & Found**에서 **Scan Folder**를 누르고 복사한 `File System` 폴더를 고릅니다.

## 평소에 해 둘 일

| 주기 | 할 일 |
|---|---|
| 처음 한 번 | 백업 알림 주기를 정하고, 백업과 복원을 한 번 시험해 봅니다 |
| 정기적으로 | **Export Data**로 백업하고 날짜를 붙여 보관합니다 |
| 브라우저 정리 전 | Studio Web을 쓴다면 반드시 먼저 백업합니다 |
| 큰 변경 전 | 복원, 전체 삭제, 작업 공간 잠금을 켜기 전에 백업합니다 |

작업 공간 잠금은 암호 문구를 잊으면 복구할 수 없으므로 백업이 특히 중요합니다. [작업 공간 잠금과 비밀값 암호화](/guide/workspace-lock-encryption/)를 보세요.

이 두 문서 항목에는 요금제 조건이 적혀 있지 않습니다.
