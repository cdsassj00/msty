## 언제 쓰나

Msty Studio의 데이터는 내 기기에 저장되고 기기 사이에 자동으로 동기화되지 않습니다. 그래서 대화를 다른 곳으로 옮기려면 직접 내보내고 가져와야 합니다. 공식 문서는 다음 경우에 내보내기를 쓰라고 안내합니다.

- 대화의 휴대용 사본이 필요할 때
- 작업을 다른 워크스페이스로 옮겨야 할 때
- Media Studio 세션을 보존하고 싶을 때

사무실 PC에서 하던 대화를 집 PC에서 이어 가거나, 정리한 대화를 동료에게 넘겨줄 때 쓰는 기능입니다.

## 내보내는 순서

1. 대화를 열고 오른쪽 위의 줄임표 메뉴를 누릅니다.
2. **Export Conversation**을 고른 뒤 **As JSON** 또는 **As ZIP**을 고릅니다.
3. 저장할 위치를 정합니다.

## 두 가지 형식

| 구분 | **As JSON** | **As ZIP** |
|---|---|---|
| 만들어지는 파일 | `.json` 파일 하나 | `.mstyconv` 파일 하나 |
| 담기는 내용 | 대화 구조와, 파일 안에 포함된 첨부 데이터 | 대화 메타데이터, 대화와 Split 데이터, 참조된 파일이 든 첨부 폴더 |
| 첨부 처리 | 첨부 파일을 인코딩해 JSON 안에 넣습니다 | 첨부 파일을 폴더에 따로 담습니다 |
| 맞는 경우 | 작은 대화, 텍스트 기반 파일 하나가 필요할 때 | 미디어가 많은 대화, 큰 첨부, 가장 옮기기 좋은 형태가 필요할 때 |

### JSON에 대해 알아 둘 점

- 문서, 이미지, 웹페이지, YouTube 첨부, 참조된 미디어는 해당 파일이 있을 때 함께 포함됩니다.
- 첨부를 인코딩해 넣기 때문에 파일이 상당히 커질 수 있습니다.
- 포함된 첨부의 합계가 **10MB 이상**이면 Msty가 ZIP 형식을 권합니다.

고르기 어렵다면 첨부가 거의 없는 글 위주 대화는 JSON, 이미지나 문서를 많이 붙인 대화는 ZIP으로 생각하면 됩니다.

## 가져오는 순서

가져오기는 대화 메뉴가 아니라 **프로젝트 메뉴**에서 합니다.

1. Projects 패널에서, 가져온 대화를 넣을 프로젝트의 줄임표 메뉴를 엽니다.
2. **Import Conversation**을 고릅니다.
3. `.json` 또는 `.mstyconv` 파일을 올립니다.
4. 가져오기가 끝나면 Msty가 대화를 그 프로젝트에 추가하고 엽니다.

## 첨부 파일과 Media Studio

| 상황 | 동작 |
|---|---|
| 현재 버전의 JSON 내보내기 | 참조된 첨부 파일을 파일 안에 포함하고, 가져올 때 복원합니다 |
| `.mstyconv` 가져오기 | 함께 든 첨부 폴더에서 파일을 복원합니다 |
| 같은 저장 파일 이름의 첨부가 워크스페이스에 이미 있을 때 | 파일을 중복해서 만들지 않습니다 |
| Media Studio 내보내기 | 첨부 파일이 포함되어 있으면 저장된 세션 상태와 참조 미디어가 보존됩니다 |

### 예전에 내보낸 JSON을 가져올 때

예전 버전에서 내보낸 JSON에는 첨부 데이터가 들어 있지 않을 수 있습니다. 이 경우 Msty는 **가져올 워크스페이스에 이미 있는 첨부만** 다시 연결할 수 있습니다. 첨부가 빠진 채 가져와졌다면 이 경우에 해당하는지 확인하세요.

## 알아 둘 점

다음 내용은 이 문서 페이지에 설명이 없습니다.

- 여러 대화를 한 번에 내보내는 방법
- 내보낸 파일의 암호화 여부

내보낸 파일에는 대화 내용과 첨부가 그대로 들어 있습니다. 사내 자료가 포함된 대화라면 파일을 보관하고 전달하는 경로를 조심해서 정해야 합니다.
