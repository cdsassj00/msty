## 무엇을 정리하는가

대화가 수십 개를 넘으면 원하는 대화를 찾기 어려워집니다. Msty Studio는 작업 공간 안에서 대화를 프로젝트 폴더로 묶게 해 줍니다. 구조는 컴퓨터의 폴더와 하위 폴더와 같습니다.

- **작업 공간**: 가장 큰 구분. [작업 공간 만들고 옮기기](/guide/workspace-basics/) 참고.
- **프로젝트(Project)**: 작업 공간 안의 폴더.
- **하위 프로젝트(Child Project)**: 프로젝트 안의 폴더.
- **대화(Conversation)**: 폴더 안에 들어가는 개별 대화.

요금 페이지의 비교표에서 "Projects Folder Management"는 Free에서 Limited로 표시되어 있습니다. 무엇이 제한되는지는 요금 페이지와 이 문서 항목에 설명이 없습니다.

## 프로젝트 만들기

1. **New Conversation** 옆의 메뉴 아이콘을 누릅니다.
2. **Create New Project**를 고릅니다.
3. 창이 열리면 프로젝트의 기본값을 정합니다.

프로젝트를 만들 때 정할 수 있는 기본값은 네 가지입니다.

| 항목 | 뜻 |
|---|---|
| 프로젝트 이름 | 폴더 이름 |
| 설명 | 이 프로젝트가 무엇인지 적는 메모 |
| 시스템 프롬프트 | 이 프로젝트의 대화에 적용할 지시문 |
| 도구와 부가 기능 | 이 프로젝트에서 켤 도구와 add-on |

프로젝트가 단순한 폴더와 다른 점이 여기에 있습니다. 예를 들어 "계약서 검토" 프로젝트에 "항상 조문 번호를 인용해 답하라"는 시스템 프롬프트를 넣어 두면, 그 프로젝트에서 대화를 시작할 때마다 같은 지시를 다시 쓸 필요가 없습니다.

## 하위 프로젝트 만들기

1. 프로젝트 폴더 옆의 말줄임표(…) 아이콘을 누릅니다.
2. **Add New Project**를 고릅니다.
3. 프로젝트를 만들 때와 같은 창에서 이름, 설명, 시스템 프롬프트, 도구를 정합니다.

예를 들어 "2026 사업계획" 프로젝트 아래에 "시장 조사", "예산", "발표 자료" 하위 프로젝트를 두는 식입니다.

## 대화 하나를 정리하기

대화의 말줄임표(…) 아이콘을 누르면 다음 작업을 할 수 있습니다.

| 작업 | 설명 |
|---|---|
| 제목 고치기 | 대화 제목을 바꿉니다 |
| 복제(Clone) | 같은 대화를 하나 더 만듭니다 |
| 이동(Move) | 다른 프로젝트 폴더로 옮깁니다 |
| 북마크 | 대화에 북마크를 붙입니다 |
| 작업 공간으로 복사·이동 | 다른 작업 공간으로 보냅니다 |
| Forge Mode로 변환 | 대화를 Forge Mode로 바꿉니다 |
| 삭제 | 대화를 지웁니다 |

대화를 복제해 두면 원래 흐름을 보존한 채 다른 방향으로 질문을 이어 갈 수 있습니다. Forge Mode는 요금 비교표에서 Aurum 이상 기능으로 표시되어 있습니다.

## 여러 대화를 한꺼번에 다루기

1. **Shift** 또는 **Ctrl**(Mac에서는 **Cmd**)을 누른 채 대화를 여러 개 고릅니다.
2. 한꺼번에 옮기거나 지웁니다.

문서에 나온 일괄 작업은 이동과 삭제 두 가지입니다.

## 최근 대화와 고정

- 최근 대화는 프로젝트 사이드바의 **Recents** 폴더에 나옵니다.
- 고정한 대화도 **Recents** 아래에 나옵니다.
- 고정하려면 대화의 말줄임표 메뉴에서 핀 아이콘을 누릅니다.

매일 여는 대화는 고정해 두면 찾는 시간이 줄어듭니다.

## 정렬과 표시 방식 바꾸기

필터 아이콘을 누르면 검색 칸과 정렬·표시 버튼이 나옵니다. **Sort and Display**를 누르면 선택지가 보입니다.

| 대상 | 선택지 |
|---|---|
| 프로젝트 폴더 정렬 | 프로젝트 이름 또는 만든 날짜, 오름차순 또는 내림차순 |
| 하위 프로젝트가 있는 폴더 | 하위 폴더를 먼저 보일지, 대화를 먼저 보일지 |
| 대화 정렬 | 대화 제목, 만든 날짜, 최근 활동 날짜, 오름차순 또는 내림차순 |
| 맨 위에 둘 대화 | 고정한 대화 또는 북마크한 대화 |
| 표시 여부 | Recents 폴더, Archived 폴더, 빈 폴더, 폴더 안의 대화 수 |

대화가 많다면 "최근 활동 날짜 내림차순"으로 두고 고정한 대화를 맨 위에 올리는 구성이 무난합니다.

## 하위 프로젝트를 최상위로 올리기

하위 프로젝트가 커져서 독립된 프로젝트로 다루고 싶을 때 씁니다.

1. 옮길 폴더를 누릅니다.
2. 폴더 옆의 말줄임표(⋯) 아이콘을 누릅니다.
3. **Move folder to root**를 고릅니다.

폴더와 그 안의 대화, 하위 폴더가 모두 작업 공간 최상위로 올라갑니다. 안쪽 구조는 그대로 유지됩니다.

## 오래된 대화 보관하기

대화를 지우지 않고 목록에서 치우는 방법입니다.

- 위치: **Settings > General > Conversations**
- 며칠보다 오래된 대화를 보관할지 날짜 수를 정합니다. 자동으로 하게 둘 수도 있고 직접 실행할 수도 있습니다.
- 보관한 대화는 삭제되지 않습니다. 프로젝트 폴더 목록의 **Archive** 폴더에 나옵니다.
- **Archive** 폴더가 보이지 않으면 **Sort and Display**의 표시 여부에서 켭니다.

## 정리 방식 예시

문서에는 권장 구조가 따로 없습니다. 아래는 사무 업무에 맞춰 본 예시입니다.

| 단계 | 구성 |
|---|---|
| 작업 공간 | "회사 업무" |
| 프로젝트 | "주간 보고", "계약 검토", "교육 자료" |
| 하위 프로젝트 | "계약 검토" 아래에 "A사", "B사" |
| 고정 | 매주 여는 "주간 보고 양식" 대화 |
| 보관 | 90일 지난 대화는 자동 보관 |

이렇게 해 두면 프로젝트마다 시스템 프롬프트가 달라서 같은 모델이라도 업무에 맞게 답하고, 오래된 대화는 목록에서 빠지되 필요하면 다시 찾을 수 있습니다.

## 알아 둘 점

- 프로젝트와 대화 개수의 상한은 문서에 없습니다.
- 삭제한 대화를 되살리는 방법은 이 문서 항목에 적혀 있지 않습니다. 지우기 전에 보관 기능을 먼저 고려하세요.
- 전체 데이터 백업은 [데이터 백업과 복구](/guide/settings-backup-lost-found/)에서 다룹니다.
