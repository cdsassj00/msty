## 이 글에서 다루는 것

한국어 사용자가 Msty Studio를 쓸 때 부딪히는 문제는 두 가지입니다. 화면이 영어이고, 공식 문서도 영어입니다. 이 글은 공식 문서의 두 항목을 묶어 각각의 해결 방법을 정리합니다.

- Language Support: 화면 언어 지원 현황과 번역 참여 방법
- Use Studio Docs with AI Tools: 공식 문서를 AI 도구에 읽히는 방법

## 지원하는 화면 언어

2026-10-11에 확인한 공식 문서의 지원 언어는 아홉 가지입니다.

| 언어 |
|---|
| 영어 (미국) |
| 영어 (영국) |
| 스페인어 |
| 프랑스어 |
| 독일어 |
| 러시아어 |
| 일본어 |
| 중국어 (간체) |
| 포르투갈어 (브라질) |

**한국어는 이 목록에 없습니다.** 따라서 메뉴와 버튼은 영어(또는 위 언어 가운데 하나)로 써야 합니다. 이 사이트의 가이드가 메뉴 이름을 **Model Hub**, **Add Provider**처럼 영어 그대로 굵게 적는 것도 그 때문입니다. 화면의 글자와 글의 글자를 그대로 맞춰 볼 수 있습니다.

화면 언어를 바꾸는 메뉴가 어디에 있는지는 Language Support 문서 항목에 적혀 있지 않습니다.

### 화면이 영어여도 대화는 한국어로 됩니다

화면 언어와 대화 언어는 별개입니다. 모델에게 한국어로 물으면 한국어로 답합니다. 답의 품질은 화면 언어가 아니라 고른 모델에 달려 있습니다. 한국어를 잘하는 모델을 고르는 일은 [모델 고르기](/models/)를 참고하세요.

Studio가 뒤에서 쓰는 지시문 때문에 대화 제목 같은 것이 영어로 만들어질 수 있습니다. 이것은 [기본 프롬프트 고치기](/guide/settings-default-prompts/)에서 바꿀 수 있습니다.

## 번역은 사용자가 함께 만듭니다

문서에 따르면 Msty Studio의 언어 지원은 사용자 참여 방식(crowd-sourcing)으로 진행됩니다. 번역은 GitHub의 i18n 저장소(cloudstack-llc/msty-studio-i18n)에서 받습니다. 한국어가 추가되려면 누군가 번역을 만들어 올려야 한다는 뜻입니다.

### 번역에 참여하는 방법

문서가 설명하는 도구와 순서입니다.

1. **Developer Mode를 켭니다.** 앱 안의 글자마다 그 글자의 키(key)가 표시됩니다. 무엇을 번역해야 하는지 볼 수 있습니다.
2. **서식 JSON 파일을 내려받습니다.** 번역을 시작할 바탕 파일입니다.
3. **번역합니다.** 키는 그대로 두고 값만 한국어로 바꿉니다.
4. **Locale JSON 파일을 가져와 미리 봅니다.** 내 번역이 앱에서 어떻게 보이는지 확인합니다.
5. **풀 리퀘스트를 올립니다.** i18n 저장소에 올려 정식 반영을 요청합니다.

### 알아 둘 제한

가져온 locale 파일은 앱을 다시 시작하면 유지되지 않습니다. 문서는 이 기능이 시험용이라고 밝힙니다. 번역 파일을 넣어 한국어 화면으로 계속 쓰는 용도로는 맞지 않습니다. 계속 쓰려면 번역이 저장소에 반영되어 앱에 들어가야 합니다.

### 오른쪽에서 왼쪽으로 쓰는 언어

문서는 RTL 언어 번역도 환영하며, Msty Studio에 이미 RTL 화면 구성이 들어 있다고 적었습니다. 한국어와는 관계가 없지만, 설정의 Appearance에 RTL 항목이 있는 이유입니다.

## 공식 문서를 AI 도구에 읽히기

공식 문서는 영어이고 분량이 많습니다. Msty는 문서 전체를 AI 도구가 읽기 좋은 텍스트 파일 하나로 묶어 공개합니다. 이 파일을 AI 도구에 넣으면 한국어로 질문하고 한국어로 답을 받을 수 있습니다.

### 두 가지 주소

| 파일 | 주소 | 쓰는 경우 |
|---|---|---|
| 전체 문서 텍스트 | `https://docs.msty.ai/studio/studio-docs.txt` | AI 도구가 큰 텍스트를 받아들일 수 있을 때 |
| 문서 색인 | `https://docs.msty.ai/studio/llms.txt` | 도구가 간단한 문서 색인을 원할 때 |

전체 문서 파일에는 공개된 Studio 문서가 하나로 들어 있습니다. 색인 파일은 주요 문서 페이지 목록과 전체 문서 파일로 가는 링크를 담고 있습니다.

문서가 밝힌 목적은, AI 도구가 모델에 내장된 지식에만 기대지 않고 최신 공식 문서를 근거로 답하게 하는 것입니다. 모델의 내장 지식은 예전 Msty App 시절의 내용일 수 있어 지금의 Studio와 맞지 않을 수 있습니다.

### 어떤 때 쓰는가

문서가 든 쓰임새입니다.

- Msty Studio Desktop 또는 Studio Web 설정하기
- 온라인 제공업체나 로컬 모델 연결하기
- Workspaces, Knowledge Stacks, Toolbox, Agent Mode, Settings 이해하기
- 고객 지원 답변이나 신입 안내문 만들기
- 현재 Studio 기능에 의존하는 작업 흐름 짜기
- 예전 Msty App 문서와 Studio의 동작 비교하기

### AI 도구에 넣는 순서

1. 문서 주소를 복사합니다.
2. Msty 문서를 쓰려는 AI 도구를 엽니다.
3. Add URL, Add source, Custom docs, Knowledge base, Live context, Web context, Reference material 같은 이름의 항목을 찾습니다.
4. 주소를 붙여 넣습니다.
5. 도구에 새로 고침, 수집, 동기화, 재색인 기능이 있으면 실행해 최신 문서를 불러옵니다.
6. Msty Studio 문서를 근거로 답하라고 요청합니다.

문서는 특정 AI 도구별 절차를 따로 적지 않았습니다. 위 순서는 주소나 자료를 넣는 기능이 있는 도구라면 어디에나 적용됩니다.

### 질문하는 방법

문서는 프롬프트 두 가지를 제안합니다. 뜻을 옮기면 이렇습니다.

- 일반용: 이 문서를 근거로 삼아 답하고, 문서에 없는 내용은 추측하지 말고 없다고 분명히 말해 달라.
- 문제 해결용: 이 문서를 근거로 문제를 해결하되, 단계별로 설명하고 각 단계가 Studio의 어느 기능 또는 설정 화면에 해당하는지 밝혀 달라.

한국어로 쓸 때는 한 가지를 더하면 좋습니다. "메뉴와 버튼 이름은 영어 원문 그대로 적어 달라"는 요청입니다. 화면이 영어이므로 번역된 메뉴 이름으로는 찾을 수 없습니다.

## Msty Studio 안에서 해 보기

Studio 자체가 AI 도구이므로 Studio 안에서도 같은 일을 할 수 있습니다. 방법은 두 가지입니다.

| 방법 | 순서 | 조건 |
|---|---|---|
| Knowledge Stacks | 전체 문서 텍스트 파일을 내려받아 Knowledge Stack에 넣습니다 | Free에서는 Limited |
| Live Contexts | 전체 문서 주소를 Live Context로 등록합니다 | Aurum 이상 |

문서의 팁에도, 도구가 외부 주소를 가져오지 못하면 텍스트 파일을 내려받아 문서 자료로 직접 올리라고 나와 있습니다. Knowledge Stacks 방식이 그것입니다. 전체 문서는 분량이 많으므로 Live Context의 Push 모드로 넣으면 대화마다 큰 맥락을 쓰게 됩니다. [Live Context 예제](/guide/settings-live-context-examples/)의 주의점을 참고하세요.

## 문서의 팁

- 도구가 큰 텍스트를 받을 수 있으면 전체 문서 파일을 씁니다.
- 도구가 간단한 색인을 원하면 `llms.txt`를 씁니다.
- 도구가 외부 주소를 저장해 두는 방식이라면 주기적으로 새로 고침하거나 재색인합니다. 문서는 계속 바뀝니다.
- 라이선스 키, API 키, 비공개 작업 공간 데이터를 외부 AI 도구에 붙여 넣지 않습니다.
- 도구가 외부 주소를 가져오지 못하면 텍스트 파일을 내려받아 직접 올립니다.

## 답을 믿기 전에

AI 도구가 문서를 근거로 답하더라도 틀릴 수 있습니다. 메뉴 경로나 요금제 조건처럼 틀리면 곤란한 내용은 답이 가리키는 문서 항목을 직접 열어 확인하세요. 이 사이트의 가이드 글 끝에 있는 "참고한 문서" 링크도 같은 용도입니다.
