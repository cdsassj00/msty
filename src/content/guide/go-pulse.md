## Pulse란

**Pulse**는 Go의 비공개 브리핑 화면입니다. 최근 작업을 살펴보고 네 가지 질문에 답합니다.

- 무엇이 주의를 필요로 하는가
- 무엇이 아직 열려 있는가
- Go가 무엇을 묶거나 정리해 줄 수 있는가
- 어떤 패턴이 남겨 둘 만한가

빈 입력창에서 시작하는 대신 현재 상태에서 출발하고 싶을 때 씁니다. 앱의 Pulse 버튼으로 열고, 설정은 **Settings > General**에서 합니다.

예를 들어(필자가 든 예입니다) 월요일 아침에 Go를 열었을 때, 지난주에 실패한 예약 작업 하나와 끝내지 못한 보고서 대화 두 개, 폴더에 넣지 않은 대화 여러 개가 카드로 정리되어 있는 모습을 생각하면 됩니다.

## Pulse가 아닌 것

문서는 Pulse의 경계를 분명히 합니다. Pulse는 [Mission Control](/guide/go-mission-control/)이 아니고, 감사 기록도 아니고, 자동 실행 엔진도 아닙니다. 브리핑을 하고, 사용자가 직접 고르는 동작으로 안내할 뿐입니다. Pulse가 일을 지어내거나 조용히 실행해서는 안 된다고 문서는 적습니다.

## Pulse가 보여 줄 수 있는 것

- 사용자를 기다리는 보류되거나 실패한 작업
- 최근 대화에서 열려 있는 흐름
- 폴더에 넣지 않은 대화 같은 정리 거리
- 반복된 작업에서 나온 재사용 가능한 작업 흐름 아이디어
- 폴더 메모리 후보와 학습 패턴
- 검토가 필요한 Playbook, Task, 일정 항목

## 설정 방법

Pulse는 모델을 명시적으로 배정해야 실행됩니다.

1. **Settings > General**을 엽니다.
2. **Pulse**를 켭니다.
3. 안내가 뜨면 Pulse 모델을 고릅니다.
4. Pulse가 켜졌는지 확인합니다.
5. 최신 브리핑이 필요하면 Pulse 버튼이나 서랍에서 **Refresh Pulse**를 누릅니다.

General Settings 문서에 따르면 Pulse에 필요한 조건은 세 가지입니다. Pulse가 켜져 있고, Pulse 모델이 선택되어 있고, 그 모델을 돌릴 수 있는 제공업체가 하나 이상 보여야 합니다.

Setup 문서와 Tasks 문서는 Pulse를 켜기 전에 모델부터 정해 두라고 권합니다. 모델은 **Settings > Model Assignments**의 `Pulse` 항목으로도 지정합니다. [모델 제공업체 설정](/guide/go-model-providers/)을 참고합니다.

### 자동 새로 고침

Pulse를 켜면 Go가 `Refresh Pulse`라는 이름의 잠긴 관리형 Task를 만듭니다. 이 Task는 30분마다 브리핑을 새로 고칩니다. Pulse를 끄면 이 Task는 일시 정지됩니다.

Tasks 문서는 이 Task를 일반 사용자 자동화처럼 다루지 말라고 합니다. 카드가 오래되어 보이면 Task를 건드리지 말고 Pulse 버튼이나 서랍에서 직접 새로 고칩니다.

## Pulse가 살펴보는 것

- 대화와 최근 메시지
- 열린 목표와 세션 상태
- 예약 작업과 최근의 전달 실패
- Playbook과 보류 중인 개선 제안
- 대화 폴더, 폴더에 넣지 않은 대화, 폴더 메모리 후보
- 스킬, 에이전트, Playbook, 예약 Task, Task Force 항목 같은 작업 흐름 자산

모델은 이렇게 모인 구조화된 사실을 간결한 브리핑으로 바꾸는 데 쓰입니다. 그래서 문서는 최근 작업을 읽고 정확히 요약할 수 있다고 믿는 모델을 고르라고 합니다.

여기서 생각해 볼 점이 있습니다. Pulse 모델은 최근 대화와 작업 내용을 읽습니다. 클라우드 모델을 Pulse에 배정하면 그 내용이 해당 제공업체로 전송된다는 뜻이므로, 민감한 업무라면 로컬 모델을 배정하는 편이 맞습니다. 이 문단은 문서의 동작 설명에서 필자가 끌어낸 주의 사항이며, 문서에 직접 적힌 문장은 아닙니다.

## 다섯 구역

Pulse 카드는 운영 목적에 따라 묶입니다.

| 구역 | 들어가는 것 |
|---|---|
| **Needs You** | 승인, 실패한 실행, 막힌 작업, 검토 대기 |
| **Suggested Actions** | Go가 이어 가거나, 정리하거나, 묶거나, 재사용 자산으로 바꾸는 것을 도울 수 있는 작업 |
| **Open Threads** | 시작했지만 끝나지 않은 것으로 보이는 대화나 목표 |
| **Clean Up** | 폴더에 넣지 않은 대화 같은 정리 작업 |
| **Patterns** | Go가 알아챈 학습 항목. 남길지, 고칠지, 잊을지 사용자가 정합니다 |

카드에는 근거 수, 최신 정도, 원본의 시점, 주 동작이 표시될 수 있습니다.

## 카드에서 할 수 있는 동작

동작은 모두 사용자가 직접 고릅니다. 카드에 따라 다음을 할 수 있습니다.

- 관련 대화, Task, Playbook, 메모리, 에이전트, 설정 영역 열기
- 작업 흐름 묶음 초안 검토하기
- 대화 자동 정리하기
- 카드 닫기(Dismiss)
- 카드 나중으로 미루기(Snooze)
- 학습 패턴을 남기기, 고치기, 잊기

카드가 오래되었다면 Pulse를 새로 고치거나 카드를 닫습니다.

## 운영 요령

- 큰 작업을 시작하기 전에 Pulse로 먼저 분류합니다.
- 학습 제안이나 작업 흐름 제안을 받아들이기 전에 근거를 검토합니다.
- 오래된 카드는 닫아서 다음 브리핑이 쓸모 있게 유지합니다.
- 비용이 중요하면 Pulse 모델을 가장 성능이 좋은 대화 모델과 따로 둡니다.
- Pulse는 신호를 주는 층입니다. 작업의 책임이나 Mission Control을 대신하지 않습니다.

## 메모리 검토와의 연결

Pulse는 폴더 메모리 후보와 학습 패턴을 카드로 띄울 수 있습니다. [Memory Bank](/guide/go-memory-bank/) 문서는 이 카드를 자동으로 저장되는 기억이 아니라 의도적인 검토를 권하는 알림으로 다루라고 합니다. 근거가 된 폴더 메모리 항목이나 원래 대화를 확인한 뒤 받아들일지 정합니다.

## 문제 해결

Pulse가 브리핑을 만들지 않을 때 확인할 순서입니다.

1. **Settings > General**에서 Pulse가 켜져 있는지 확인합니다.
2. Pulse 모델이 선택되어 있는지 확인합니다.
3. 선택한 제공업체가 보이고 사용 가능한지 확인합니다.
4. Pulse를 수동으로 새로 고칩니다.
5. Pulse가 요약할 만큼 최근 작업이 있는지 확인합니다.

## 알아 둘 점

- 30분이라는 새로 고침 간격을 바꿀 수 있는지는 공식 문서에 설명이 없습니다. 문서는 해당 Task가 잠겨 있다고 적습니다.
- "비공개"가 구체적으로 어떤 범위를 뜻하는지(예: 다른 기기나 팀원에게 보이지 않는지)는 공식 문서에 설명이 없습니다.
