## 무엇을 하는 기능인가

Msty Studio는 이미지 생성을 지원하는 모델로 이미지를 만들 수 있습니다. 따로 켜는 스위치가 있는 것이 아니라, 모델의 용도 태그에 **Image**가 올바르게 붙어 있어야 동작합니다. 이 글은 그 태그를 맞추는 방법을 설명합니다.

발표 자료에 넣을 삽화를 만들거나, 이미 만든 이미지의 색을 바꿔 달라고 요청하는 작업에 씁니다.

## 핵심은 Image 용도 태그

이미지 생성이 가능한 모델 대부분은 처음부터 **Image** 용도가 켜진 상태로 들어옵니다. 이 경우 따로 할 일이 없습니다.

직접 손봐야 하는 경우는 둘입니다.

- 이미지 생성을 지원한다는 것을 알고 있는데 **Image**가 꺼져 있는 모델
- 직접 추가한 사용자 지정 모델

### 사용자 지정 모델을 추가할 때

모델을 추가하는 화면에서 용도로 **Image**를 선택합니다.

### 이미 있는 모델을 고칠 때

1. 대화 화면에서 모델 선택 목록을 엽니다.
2. 고칠 모델을 찾아 편집 아이콘을 누릅니다.
3. 열리는 창에서 모델의 용도를 고칩니다.

## 이미지 전용 모델과 멀티모달 모델 구분하기

용도를 고를 때 가장 중요한 부분입니다. 모델이 이미지만 만드는 모델인지, 글과 이미지를 함께 다루는 멀티모달 모델인지에 따라 선택이 달라집니다. Msty는 이 설정을 보고 이미지 생성 요청을 처리하는 방식을 정합니다.

| 모델 종류 | 용도 선택 |
|---|---|
| 이미지 전용 모델 (멀티모달 기능이 없는 모델) | **Image 하나만** 선택합니다 |
| 멀티모달 모델 | **Image 외에 다른 용도도** 함께 선택합니다. 이미지를 지원하는 멀티모달 모델은 대개 글도 지원하므로 **Text**를 함께 고르는 식입니다 |

이미지 생성 중 오류가 나면 먼저 이 용도 설정이 모델 종류에 맞는지 확인하세요. 공식 문서가 안내하는 첫 번째 점검 항목입니다.

## 고급 설정

이미지의 크기와 장수 같은 설정은 모델 파라미터에 넣을 수 있습니다. 공식 문서는 다음 두 가지를 예로 듭니다.

| 설정 | 예시 | 뜻 |
|---|---|---|
| 가로세로 비율 | `size : 1536x1024` | 만들 이미지의 크기 |
| 생성 장수 | `n: 2` | 한 번에 만들 이미지 수 |

모든 모델이 이 설정을 지원하지는 않습니다. 공식 문서는 OpenAI 모델에서는 동작할 가능성이 높지만 Gemini에서는 동작하지 않을 수 있다고 설명합니다. 쓰려는 모델이 어떤 값을 받는지는 해당 제공업체의 문서에서 확인해야 합니다.

## 알아 둘 점

이 문서 페이지는 용도 태그와 두 가지 파라미터만 다룹니다. 어떤 제공업체의 어떤 모델이 이미지 생성을 지원하는지에 대한 목록은 공식 문서에 설명이 없습니다.
