## Context Studio가 하는 일

**Context Studio**는 대화에 붙일 자료를 저장하고, 정리하고, 미리 보고, 다시 쓰는 중앙 보관함입니다. 이전 이름은 **Attachment Manager**였습니다.

채팅에 파일을 한 번 붙이고 끝나는 것이 아니라, 문서·이미지·영상·웹페이지·YouTube 자막을 여러 대화에서 계속 쓰고 싶을 때 사용합니다. 예를 들어 사내 규정집 PDF와 조직도 이미지를 넣어 두면, 새 대화를 열 때마다 다시 올리지 않고 보관함에서 골라 붙일 수 있습니다.

## 여는 방법

- **사이드바에서**: 메인 사이드바의 클립 아이콘을 누릅니다.
- **대화에서**: 채팅의 첨부 아이콘을 누르고 **Browse Existing Attachments**를 고릅니다. 이렇게 열었을 때는 붙일 항목을 선택한 뒤 선택 결과를 채팅에 적용합니다.

## 넣을 수 있는 자료

| 종류 | 설명 |
|---|---|
| 문서 | 파일을 올려 두고 여러 대화에서 텍스트 자료로 재사용합니다 |
| 이미지 | 대화와 Media Studio 작업에 쓸 시각 자료를 보관합니다 |
| 영상 | 영상 파일을 재사용 가능한 시각 자료로 추가합니다 |
| 웹페이지 | 가져온 웹페이지 내용을 저장합니다 |
| YouTube 링크 | 영상 정보와 자막을 가져옵니다 |

추가하는 방법은 다음과 같습니다.

- 파일을 Context Studio 창으로 끌어다 놓기
- **Add Attachment**: 파일 올리기
- **Add Website**: 웹페이지 추가
- **Add YouTube**: YouTube 링크 가져오기

## 정리하기

- 자료가 많으면 폴더로 관리합니다. 최상위 폴더는 Context Studio의 추가 메뉴(overflow menu)에서 만듭니다.
- 파일과 폴더를 끌어서 위치를 바꿉니다.
- 빠른 필터로 폴더나 파일을 이름으로 찾습니다.
- 이름, 만든 날짜, 수정한 날짜로 정렬합니다.
- 중요한 항목은 즐겨찾기로 표시합니다.
- 폴더 메타데이터에 폴더 내용을 요약해 둘 수 있습니다. 이 요약은 필터링에 쓰이고, 아래에서 설명할 Dynamic Mode가 어떤 자료가 관련 있는지 판단하는 데도 쓰입니다.

## 항목 살펴보기

항목을 선택하면 **inspector**(상세 패널)가 열립니다. 여기서 볼 수 있는 내용은 다음과 같습니다.

- 이미지, 영상, 웹페이지, YouTube 미리보기
- 문서, 웹페이지, YouTube 자막을 텍스트로 변환한 미리보기
- 파일 형식, 크기, 추가한 날짜, 수정한 날짜
- 짧은 설명, 긴 설명, 태그
- **Associations**: 이 항목이 어디에서 쓰이고 있는지

메타데이터 항목은 고치면 자동으로 저장됩니다. 항목을 선택해 처리(process)시키면, 설정해 둔 메타데이터 모델이 설명과 태그를 만들어 줍니다.

## 대화에서 자료 쓰기

방법이 두 가지입니다.

### 특정 자료를 골라 붙이기

채팅 입력란의 첨부 아이콘을 누르고, 자료 종류를 고른 뒤 항목을 선택합니다. 선택한 자료는 그 대화에서 모델이 볼 수 있으며, 대화 중에 선택하거나 선택 해제할 수 있습니다.

### Dynamic Mode

도구를 쓸 수 있는 모델이 보관함을 **필요할 때 직접 검색**하는 방식입니다. 선택한 자료를 처음부터 전부 프롬프트에 넣지 않습니다.

공식 문서는 다음 경우에 쓰라고 안내합니다.

- 보관함이나 폴더가 너무 커서 통째로 넣을 수 없을 때
- 모델이 가장 관련 있는 파일만 찾아 쓰게 하고 싶을 때
- 메타데이터, 요약, 태그가 잘 정리되어 있을 때
- 검색 범위를 특정 폴더로 한정하거나 보관함 전체로 넓히고 싶을 때

조건은 다음과 같습니다.

- **Aurum** 또는 **Enterprise** 이용 권한이 있어야 합니다.
- 도구(tools)를 지원하는 모델이 필요합니다. 모델이 도구를 지원하지 않으면 특정 자료를 골라 붙이는 방식을 씁니다.

## Media Studio와 함께 쓰기

- 이미지나 영상 첨부에서 새 [Media Studio](/guide/studio-media/) 세션을 시작할 수 있습니다.
- 저장해 둔 이미지, 영상, 문서를 Media Studio의 참고 자료로 재사용합니다.
- 생성된 미디어는 세션과 함께 내보내면 이후 대화에서도 쓸 수 있습니다.

## 설정

Context Studio의 설정 버튼에서 **Context Studio Settings**를 엽니다.

| 설정 | 설명 |
|---|---|
| **Metadata on New Uploads** | 메타데이터 모델이 지정되어 있으면 새로 올린 문서와 이미지의 메타데이터를 자동으로 만듭니다 |
| **Metadata Processing Models** | 이미지용(비전) 모델과 문서용 메타데이터 모델을 **Model Squad**에서 지정합니다 |
| **Image Reduction Defaults** | 이미지 축소 방식과 품질의 기본값을 정합니다 |
| **Web Fetch** | 웹페이지를 가져올 방법을 Studio 기본 방식과 **Jina** 중에서 고르고, 웹 내용의 형식과 추출 관련 값을 조정합니다 |
| **Default Prompts** | Context Studio가 쓰는 프롬프트는 **Settings > Default Prompts**에서 고칩니다 |

공식 문서는 자료를 많이 쌓기 **전에** 이 설정부터 하라고 권합니다. 특히 이미지와 문서용 메타데이터 모델을 지정해 두어야 Msty가 요약, 설명, 태그를 만들어 주고, 이것이 Dynamic Mode와 필터링의 품질을 좌우합니다.

## 웹페이지를 가져오지 못할 때

Studio의 기본 웹 가져오기 방식은 데스크톱 **sidecar** 연결이 필요합니다. sidecar를 쓸 수 없는 환경이라면 Context Studio 설정에서 **Jina**를 켜고 Jina API 키를 넣습니다.
