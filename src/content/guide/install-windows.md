## 준비물

- Windows 10 또는 11, 64비트(x64)
- 모델을 받을 디스크 공간. 로컬 모델 하나가 수 GB를 차지합니다.

내 PC가 어떤 모델을 돌릴 수 있는지는 [내 PC 사양으로 돌릴 수 있는 모델 고르기](/learn/choose-model-for-your-pc/)에서 확인합니다.

## 설치 파일 받기

[Msty Studio 제품 페이지](https://msty.ai/products/studio/)나 공식 문서의 다운로드 페이지에서 Windows용 설치 파일을 받습니다. Windows용은 x64 설치 파일 하나이며 파일 이름은 `MstyStudio_x64.exe`입니다.

## 설치하기

받은 파일을 실행해 안내에 따라 설치합니다. 공식 문서는 관리자 권한으로 설치하되 **내 사용자 계정에만** 설치하라고 안내합니다. 모든 사용자용 설치는 Windows의 제약 때문에 지원하지 않습니다.

## 처음 실행하기

설치가 끝나면 Msty Studio를 엽니다. 처음 켜면 사용 목적을 묻고 첫 모델을 연결하는 화면이 나옵니다. 이어지는 과정은 [첫 실행과 모델 받기](/guide/first-run-and-models/)에서 설명합니다.

## 자주 막히는 곳

- **회사 PC에서 SSL 오류가 날 때**: 공식 문서에 PowerShell로 우회하는 방법이 있지만, 인증서 검증을 끄는 방식입니다. 회사 전산 담당자와 먼저 상의하세요.
- **예전 Msty 앱(1.x)을 쓰고 있을 때**: Studio는 따로 설치되므로 예전 앱을 지울 필요가 없습니다. 예전 앱의 일부 데이터를 Studio로 옮겨 주는 도구가 있습니다.
