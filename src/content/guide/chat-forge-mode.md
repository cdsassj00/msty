## Forge Mode란

**Forge Mode**는 대화 화면이 아니라 문서 편집 화면에서 글을 쓰는 방식입니다. 서식 있는 글 편집, 본문 안에서 바로 고치기, AI 모델을 통한 내용 생성을 한 화면에서 합니다.

일반 대화에서는 모델이 긴 글을 통째로 다시 써 주기 때문에, 한 문단만 고치고 싶어도 전체를 다시 받아야 합니다. Forge Mode에서는 고칠 부분을 선택해 그 부분만 다시 쓰게 할 수 있습니다. 보고서나 안내문처럼 여러 번 손봐야 하는 글에 맞습니다.

## 여는 방법

두 가지입니다.

| 방법 | 메뉴 |
|---|---|
| 새로 시작하기 | **New Conversation** 메뉴에서 **New Forge Canvas** |
| 기존 대화를 바꾸기 | 대화 메뉴에서 **Convert to Forge Canvas** |

모델과 대화하며 초안을 만든 뒤, 그 대화를 Forge Canvas로 바꿔 다듬는 순서로 쓸 수 있습니다.

## 주요 기능

공식 문서는 Key Features 항목에 **Aurum Perk** 표시를 붙여 두었습니다.

| 기능 | 하는 일 |
|---|---|
| **Ask** | 선택한 글에 대해 모델에게 메시지를 보냅니다 |
| **Rewrite** | 선택한 글을 다시 씁니다. 쉽게 풀기, 짧게 또는 길게 만들기, 이모지 넣기, 어조 바꾸기 등 |
| 서식 편집 도구 | 글자 꾸밈과 코드 블록을 포함한 스타일을 적용합니다 |
| 손잡이 아이콘 | 글 블록을 잡아 위치를 옮깁니다 |
| **+** 아이콘 | 새 글 블록을 추가하고 글에 서식을 적용합니다 |

**Ask**와 **Rewrite**의 차이는 이렇습니다. Ask는 선택한 부분을 두고 모델에게 묻는 것이고, Rewrite는 선택한 부분 자체를 바꿔 쓰는 것입니다. "이 문단의 논리가 맞나요"는 Ask, "이 문단을 절반 길이로"는 Rewrite입니다.

## 문서가 언급하는 그 밖의 기능

공식 문서의 소개 문장에는 사용자 지정 프롬프트, 집중 모드, 실행 취소와 다시 실행, 실시간 협업, 고급 서식 도구가 Forge Mode의 기능으로 언급됩니다. 다만 이 기능들을 어떻게 쓰는지는 공식 문서에 설명이 없습니다.

## 알아 둘 점

이 문서 페이지는 짧습니다. 다음 내용은 공식 문서에 설명이 없습니다.

- Forge Canvas로 바꾼 대화를 다시 일반 대화로 되돌릴 수 있는지
- 작성한 글을 어떤 형식으로 내보낼 수 있는지
- Aurum 라이선스 없이 쓸 수 있는 범위
