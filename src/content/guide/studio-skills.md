## Skills Studio가 하는 일

**Skills Studio**는 [Agent Mode](/guide/agent-mode/)가 사용하는 스킬을 만들고 관리하는 전용 작업 공간입니다.

스킬은 에이전트에게 주는 작업 설명서입니다. "변경 내역 정리는 이 형식으로 작성한다", "테스트는 이 순서로 실행한다" 같은 지시를 `SKILL.md` 파일에 적어 두면, Agent Mode에서 슬래시 명령으로 불러 같은 작업을 같은 방식으로 반복할 수 있습니다.

## 여는 방법과 시작 방법

1. **Settings > Agent Mode > Skills Studio**로 갑니다.
2. 스킬을 만들거나 가져옵니다. 방법은 네 가지입니다.
   - 새 초안에서 시작하기
   - 기본 스킬 가져오기
   - 템플릿 사용하기
   - **Discover**에서 GitHub 저장소 추가하기
3. 폴더를 만들어 작업 흐름에 맞게 스킬을 배치합니다.

## 화면 구성

| 영역 | 하는 일 |
|---|---|
| **Workshop** | 스킬의 메타데이터와 `SKILL.md` 지시문을 편집하고 저장합니다. 고치고 다시 시험하는 일을 빠르게 반복하는 곳입니다 |
| **Discover** | 연결된 저장소를 둘러보고, 스킬 내용을 확인하고, 필요한 것을 설치합니다. 직접 추가한 저장소의 표시 이름을 바꿔 찾기 쉽게 할 수 있습니다 |
| 폴더와 일괄 관리 | 하위 폴더를 포함한 폴더 구조로 스킬을 정리합니다. 스킬이 많아져도 관리할 수 있게 해 줍니다 |
| 템플릿과 AI 도구 | 템플릿과 AI 초안 작성 기능으로 스킬의 설명과 지시문을 만들거나 개선합니다 |

공식 문서에서 템플릿과 AI 도구 항목에는 **Aurum Perk** 표시가 붙어 있습니다.

## 스킬을 만드는 순서

1. **Workshop**에서 새 스킬을 만듭니다.
2. 설명과 지시문을 명확하게 씁니다.
3. 태그를 붙이고 폴더에 넣습니다.
4. Agent Mode의 슬래시 명령으로 시험합니다.
5. 결과를 보고 고치거나, **Discover**에서 다른 스킬을 추가로 설치합니다.

2번 단계가 가장 중요합니다. 설명은 에이전트가 "이 스킬을 언제 써야 하는지" 판단하는 근거가 되고, 지시문은 실제 작업 방식이 됩니다. 사람에게 업무를 인계할 때처럼 조건과 순서를 빠짐없이 적습니다.

## 공식 문서가 권하는 요령

- 스킬 ID는 단순하게 짓고, 한번 정하면 바꾸지 않습니다.
- 개인용, 팀용, 실험용 스킬은 폴더로 나눠 둡니다.

## 문서에 없는 내용

`SKILL.md`의 세부 형식, 스킬 개수 제한, 요금제별 차이는 이 문서 페이지에 설명이 없습니다. 스킬을 시험하려면 Agent Mode가 먼저 설정되어 있어야 하므로, CLI 에이전트 연결은 [Agent Mode 글](/guide/agent-mode/)을 참고합니다.
