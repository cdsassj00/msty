## 무료 도구 네 가지

자료실에는 로그인 없이 쓰는 도구 네 가지가 연결되어 있습니다. 모두 msty.studio 주소에 있습니다.

| 도구 | 하는 일 |
|---|---|
| Context Explorer | 모델의 컨텍스트 창이 토큰, 쪽수, 대화 분량으로 얼마나 되는지 보여 줍니다 |
| Model Matchmaker | 몇 가지 질문에 답하면 하려는 일에 맞는 모델을 찾아 줍니다 |
| VRAM Calculator | 모델을 로컬에서 돌리는 데 필요한 그래픽 메모리를 어림합니다 |
| Model Cost Calculator | 제공업체별 가격을 비교하고 작업량에 따른 비용을 어림합니다 |

로컬 모델을 처음 고른다면 VRAM Calculator로 내 PC에서 돌릴 수 있는 크기를 먼저 확인하면 좋습니다. 모델 선택은 [모델 고르기](/models/)도 참고하세요.

## PMO 로컬 AI 백서 요약

둘째 백서는 웹 페이지로 읽을 수 있어 내용을 요약합니다. Msty가 2026년 8월에 펴낸 글이며, 한 사람의 구성을 소개한 사례입니다. 백서 스스로도 이것이 기본 구성이 아니라 의도적으로 짠 한 가지 구성이라고 밝힙니다.

### 배경

주인공은 폴란드에서 혼자 일하는 IT 프로젝트 관리자이자 PMO 컨설턴트입니다. 계약서, 입찰 서류, 계획서, 이해관계자와의 통신처럼 고객의 기밀 자료를 다룹니다. AI의 도움은 받고 싶지만 자료를 클라우드 제공업체로 보내고 싶지는 않았습니다.

### 구성

| 항목 | 내용 |
|---|---|
| 장비 | Windows 11 Pro 워크스테이션. 그래픽 메모리 72GB, 16코어 프로세서, RAM 128GB. 노트북은 단말기로 사용 |
| 모델 실행 | LM Studio가 모델을 로컬에서 실행하고, Msty Studio가 작업 공간 역할 |
| 클라우드 제공업체 | 설정하지 않음 |
| 모델 | 문서 작업용 약 27~31B급 모델 두 개, Knowledge Stacks용 8B 임베딩 모델, 폴란드어와 공공 조달 용어용 70B 모델 |
| 끈 기능 | 리랭킹, 웹 페이지를 지식 자료로 가져오기. 문서 내용이 기기 밖으로 나가지 않게 하기 위함 |
| 쓴 Studio 기능 | Personas, Crew Conversations, Knowledge Stacks, Shadow Personas |

이 장비는 개인용으로는 매우 높은 사양입니다. 같은 방식을 더 작은 모델로 시도할 수는 있지만, 백서가 그 경우의 결과를 다루지는 않습니다.

### 네 가지 작업

1. **문서 검증**: 선임 PM, 제품 책임자, 업무 분석가, IT 계약 변호사의 네 역할 페르소나가 한 문서를 차례로 검토합니다. 모호한 표현, 담당자 없는 약속, 등록되지 않은 위험, 내부 모순을 찾습니다.
2. **계약서와 입찰 서류 분석**: 자료를 Knowledge Stack에 넣고 요율, 지급 조건, 검수, 책임 한도, 해지 같은 조항을 묻습니다. 답이 인용한 조문은 원문에서 직접 확인합니다. 짧지만 중요한 조항이 버려지지 않도록 최소 청크 크기를 낮췄다고 합니다.
3. **발송 문서 점검**: Shadow Personas가 요청에 따라 문장 하나하나를 원문과 대조하고, 언어의 명확성과 내부 논리를 확인합니다.
4. **관리 산출물 작성**: 회의 녹취록에서 회의록, 담당자가 붙은 결정·할 일 목록, 위험 등록부, 현황 보고서 초안을 만듭니다.

### 결과와 한계

백서는 측정한 시간 절감 수치를 제시하지 않습니다. 절감 효과는 체감할 만했고, 빈 화면이 아니라 구조가 잡힌 초안에서 시작하는 것과 원문 대조가 줄어든 것에서 나왔다고 서술합니다.

백서가 스스로 밝힌 한계는 다음과 같습니다.

- 로컬 처리의 안전성은 사용자의 구성, 기기 보안, 행동에 달려 있습니다. 고객은 자신의 법적·계약상 의무를 따로 판단해야 합니다.
- 일반 모델은 폴란드 조달 용어를 일관되지 않게 쓰거나 지어냈습니다. 그래서 법적 정의는 원문에서만 가져옵니다.
- 모델은 조심스러운 추측을 확정된 약속으로 바꾸고, 마감일을 지어내고, 그럴듯한 숫자 오류를 냅니다. 숫자가 가장 자주 문제가 되었습니다.
- 대조 점검은 문장을 하나씩 확인할 뿐, 두 문장이 함께 참일 수 있는지는 판단하지 않습니다.
- 최종 검토와 승인은 컨설턴트의 책임입니다.

한국어 업무에 옮겨 생각하면, 법령 용어와 숫자는 반드시 원문과 대조해야 한다는 점이 가장 쓸모 있는 교훈입니다.
