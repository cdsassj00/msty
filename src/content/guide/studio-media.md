## Media Studio가 하는 일

**Media Studio**는 이미지와 영상을 만들고 다듬기 위한 전용 세션입니다. 일반 대화와 달리 참고 자료(Context), 생성 이력(History), 비교(Compare) 도구가 세션 안에 계속 유지됩니다.

행사 포스터 시안을 만든다고 하면, 로고 이미지와 지난해 포스터를 참고 자료로 넣고, 한 번에 시안 여러 장을 뽑아 나란히 비교한 뒤, 마음에 드는 한 장에 표시를 해서 다시 생성을 요청하는 식으로 진행합니다.

## 세션 시작하기

시작하는 방법은 두 가지입니다.

- **새 세션**: **New** 메뉴에서 **New Media Session**을 고릅니다.
- **기존 첨부에서 시작**: 메시지 첨부 파일의 **Open in Media Studio**를 누르거나, [Context Studio](/guide/studio-context/)에서 **Start New Media Session**을 누릅니다.

세션이 열리면 프롬프트를 입력하고, 이미지 또는 영상 모델을 고르고, 한 번에 만들 결과 개수를 정한 뒤 생성합니다.

## 모델 준비

Media Studio는 **Model Hub**의 이미지 생성 설정에 등록된 미디어 모델을 사용합니다.

- 실행 한 번에 만들 결과 개수를 정할 수 있습니다.
- 모델에 별표를 하면 Media Studio의 기본 모델이 됩니다.
- 등록된 미디어 모델이 없으면 Media Studio가 Model Hub로 바로 가는 길을 안내합니다.

## 참고 자료(Context) 다루기

- 끌어다 놓기, 클립 아이콘, 화면 캡처로 참고 자료를 추가합니다.
- 이미지, 영상, 문서를 참고 자료로 붙일 수 있습니다.
- Context Studio에 저장해 둔 항목은 다시 올리지 않고 가져다 쓸 수 있습니다.
- 항목을 **Context**, **Spotlight**, **Compare** 사이에서 옮길 수 있습니다.
- **Keep latest only**를 켜면 실행할 때마다 가장 최근에 생성된 결과만 참고 자료에 남습니다.

### 미리보기에 붙는 표시

| 표시 | 의미 |
|---|---|
| 미디어 종류 라벨 | 이미지인지 영상인지 표시합니다 |
| 파일 이름 | 참고 자료 미리보기 아래에 표시됩니다 |
| **Spotlight** 배지 | 현재 Spotlight에 올라가 있는 항목입니다 |
| **Start** | 이 이미지를 영상의 첫 프레임으로 지정합니다 |
| **End** | 이 이미지를 영상의 마지막 프레임으로 지정합니다. 선택한 모델이 끝 프레임 보간을 지원할 때만 쓸 수 있습니다 |

**Start**와 **End**는 이를 지원하는 영상 모델을 골랐을 때만 나타납니다.

## Spotlight, History, Compare

| 영역 | 역할 |
|---|---|
| **Spotlight** | 선택한 결과를 올려 두고 작업하는 주 화면입니다 |
| **History** | 생성된 결과가 쌓이는 곳입니다. 이전 결과를 다시 꺼내 쓸 수 있습니다 |
| **Compare** | 결과를 최대 3개까지 나란히 놓고 비교합니다 |

History의 각 항목에서는 다음 작업을 할 수 있습니다.

- Spotlight에 추가
- Context에 추가
- Compare 켜기/끄기
- 내려받기
- 제목 바꾸기
- 삭제

## 고쳐 가며 작업하기

- 이미지 결과에서는 **Edit Image**를 쓸 수 있습니다. 이미지 위에 표시를 하고 새 버전으로 저장합니다.
- 고친 버전은 History로 돌아가며, 새 참고 자료로 다시 쓸 수 있습니다.
- 프롬프트 이력이 세션 안에 저장되므로 이전 프롬프트를 꺼내 조금 바꿔 다시 실행하기 쉽습니다.

## 영상 생성

공식 문서 기준으로 영상 생성은 현재 다음을 지원합니다.

- xAI
- Google Veo
- Seedance
- OpenRouter의 영상 모델

참고 이미지를 쓸 수 있는지, Start/End 프레임을 지정할 수 있는지는 모델마다 다릅니다.

## 세션 내보내기와 가져오기

Media Studio 세션은 일반 대화와 같은 내보내기 절차를 사용합니다.

- 생성한 이미지나 영상, 용량이 큰 첨부가 들어 있으면 `.mstyconv` 형식으로 내보냅니다.
- 첨부 파일을 포함해 내보내면 저장된 세션 상태와 참조된 미디어가 함께 보존됩니다.

## 문서에 없는 내용

생성 한 건당 비용, 해상도나 길이 제한, 요금제별 차이는 이 문서 페이지에 설명이 없습니다. 온라인 모델로 생성하면 프롬프트와 참고 자료가 해당 제공업체로 전송된다는 점은 일반 대화와 같으므로, 사내 자료를 참고 이미지로 넣기 전에 확인이 필요합니다.
