## 메시지 동작이란

Msty Studio의 대화에서는 내 메시지와 모델의 답변마다 동작 버튼이 붙어 있습니다. 복사하고, 고치고, 갈래를 나누고, 정리하고, 지우는 일을 메시지 단위로 합니다.

자주 쓰는 동작은 메시지 바로 아래에 나와 있고, 덜 쓰는 동작(분기, 복제, 숨기기, 컨텍스트 제외, 도구 사용 내역)은 추가 동작 메뉴에 묶여 있습니다. 긴 메시지에서는 스크롤하는 동안 동작 버튼이 떠 있는 형태로 따라와 계속 누를 수 있습니다.

## 복사하기

답변을 클립보드에 복사합니다. 복사 형식을 고를 수 있습니다.

1. 메시지의 복사 버튼을 **길게 누릅니다.**
2. 나오는 형식 중 하나를 골라 복사합니다.
3. 원하는 곳에 붙여 넣습니다.

고를 수 있는 형식은 **Markdown**, **HTML**, **Formatted Text**(서식 있는 글) 세 가지입니다.

Msty Studio는 마지막으로 고른 형식을 기억합니다. 다음에 복사 버튼을 짧게 누르면 그 형식으로 복사됩니다. 답변을 문서 편집기에 서식째 붙여 넣는 일이 많다면 Formatted Text를 한 번 골라 두면 됩니다.

## 답을 다시 받거나 이어 받기

| 동작 | 하는 일 |
|---|---|
| 북마크 | 메시지를 나중에 찾기 쉽게 저장합니다. 창 위쪽의 **Bookmarks**에 모입니다 |
| 재생성(Regenerate) | 같은 질문에 새 답을 받습니다. 모델을 바꾼 뒤 새 모델로 답을 다시 받을 때도 씁니다 |
| 이어서 생성(Continue generation) | 답이 중간에 끊겼거나 더 늘리고 싶을 때 이어서 쓰게 합니다 |

## Response Metrics — 답변의 수치 보기

답변마다 입력·출력 토큰 추정치와 지연 시간을 보여 줍니다. 도구를 썼다면 어떤 도구를 사용했는지를 포함한 도구 사용 수치도 함께 나옵니다.

## 컨텍스트 조절하기

모델은 답할 때 이전 대화 내용을 함께 읽습니다. 이를 컨텍스트라고 합니다. 다음 세 가지 동작은 화면에 보이는 것과 모델이 읽는 것을 따로 조절합니다.

| 동작 | 화면 | 모델에 전달되는 컨텍스트 |
|---|---|---|
| **Context Shield** | 그대로 보임 | Shield 이전의 대화 전체가 빠집니다 |
| **Isolate Context** | 그대로 보임 | 해당 답변 하나만 빠집니다 |
| 숨기기(Hide) | 보이지 않음 | **그대로 포함됩니다** |
| 접기(Fold) | 접혀서 보임 | 공식 문서에 설명이 없습니다 |

### Context Shield

Context Shield는 그 지점 이전의 대화가 이후 입력에 영향을 주지 못하도록 막는 벽입니다. 한 대화 안에서 주제를 바꿀 때, 새 대화를 열지 않고도 앞 내용을 끊어 낼 수 있습니다.

Shield를 켠 뒤 방패 아이콘을 누르면 두 가지 메뉴가 나옵니다.

- **Remove Context Shield** — Shield를 없앱니다.
- **Generate Context Summary** — 대화의 요약을 답변 하나씩 차례로 만듭니다.

### Isolate Context

특정 답변 하나를 이후 대화의 컨텍스트에서 제외합니다. 모델이 틀린 답을 냈는데 지우기는 싫고, 그 내용이 다음 답에 영향을 주는 것만 막고 싶을 때 씁니다.

- 되돌리려면 **Remove Context Isolation**을 고릅니다.
- 대화 전체의 제외 설정을 한 번에 풀려면 오른쪽 위 줄임표 메뉴에서 **Clear All Context Isolations**를 고릅니다.

### 숨기기와 접기

**숨기기**는 메시지를 화면에서 감춥니다. 숨긴 메시지도 컨텍스트에는 계속 포함된다는 점이 Isolate Context와 다릅니다.

- 다시 보이게 하려면 옆 메시지의 응답 메뉴에서 상위·하위 메시지 숨김 해제 옵션을 누릅니다.
- 모두 다시 보이게 하려면 오른쪽 위 줄임표 메뉴에서 **Show All Hidden Messages**를 고릅니다.

**접기**는 메시지를 접어 화면을 정돈하고 특정 메시지에 집중하게 해 줍니다.

## 갈래 만들기

### Edit as Branch

추가 동작 메뉴에서 **Edit as Branch**를 고릅니다. 메시지를 고쳐 저장하면 원래 흐름을 덮어쓰지 않고 새로운 대화 갈래가 만들어집니다. 갈래에 이름을 붙이고 비교하는 방법은 [Branch Explorer](/guide/chat-branch-explorer/)에서 다룹니다.

### Use as Prompt in New Split

추가 동작 메뉴에서 **Use as Prompt in New Split**을 고르면, 그 메시지를 첫 프롬프트로 하는 새 Split이 만들어집니다. 이 Split은 다른 Split과 입력이 동기화되지 않습니다.

대화 전체를 복사하지 않고 특정 메시지만 다른 모델에 시험해 보고 싶을 때 씁니다. Split에 대해서는 [Split Chat](/guide/chat-split-chat/) 글을 보세요.

## 도구 사용 내역 보기

**View Tools Usage**는 답변에 쓰인 도구의 이름, 입력, 출력을 보여 줍니다. 모델이 어떤 도구를 어떻게 써서 답을 만들었는지 확인할 수 있습니다.

## 삭제하기

삭제 버튼은 메시지 하나만 지우는 것과 갈래를 통째로 지우는 것을 구분합니다.

| 조작 | 결과 |
|---|---|
| 삭제 버튼 클릭 | 현재 메시지만 지웁니다 |
| 삭제 버튼 우클릭 후 **Delete Message and Descendants** | 그 메시지와, 같은 갈래에서 뒤따르는 모든 답을 지웁니다 |
| **Shift**를 누른 채 위 동작 | 확인 창 없이 바로 지웁니다 |

메시지 하나만 지우면 남은 대화 흐름이 가능한 범위에서 다시 이어집니다. 그 갈래의 나머지를 일부러 없애려는 경우에만 하위 메시지까지 지우는 쪽을 고릅니다. Shift를 누르면 확인 없이 지워지므로 조심해서 써야 합니다.

## 메시지 배치 바꾸기

Modern message layout은 다음과 같이 표시합니다.

- 내 메시지는 오른쪽
- 모델의 메시지는 왼쪽
- 간결해진 모델 이름 표시
- 메시지 내용 바깥에 놓인 동작 버튼

Modern과 Classic 배치는 대화 메뉴 또는 **Settings > Conversations > Modern message layout**에서 바꿉니다.
