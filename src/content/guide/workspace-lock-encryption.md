## 무엇을 하는 기능인가

작업 공간 잠금은 암호 문구(passphrase)로 작업 공간을 잠그는 기능입니다. 잠금을 풀기 전까지 민감한 설정과 API 키가 숨겨집니다.

공용 컴퓨터나 여러 사람이 만질 수 있는 PC에서 Studio를 쓸 때, 또는 온라인 모델의 API 키가 저장되어 있어 다른 사람이 앱을 열면 곤란할 때 쓸 수 있습니다.

## 먼저 읽어야 할 경고

공식 문서는 두 가지를 분명히 경고합니다.

1. **실험 기능입니다.** 문서는 작업 공간 잠금을 experimental이라고 표시합니다. 동작이 바뀔 수 있습니다.
2. **암호 문구를 잊으면 되찾을 방법이 없습니다.** 암호 문구는 복구할 수 없고, 그 작업 공간도 복구하거나 복원할 수 없습니다.

둘째 경고가 가장 중요합니다. 암호 문구를 잊는 것은 대화와 설정을 모두 잃는 것과 같습니다. 켜기 전에 다음을 권합니다.

- 암호 문구를 비밀번호 관리 프로그램처럼 나중에 꺼내 볼 수 있는 안전한 곳에 적어 둡니다.
- 잠금을 켜기 전에 데이터를 백업합니다. 방법은 [데이터 백업과 복구](/guide/settings-backup-lost-found/)에 있습니다.

## 잠금 켜기

1. **Settings > General**로 갑니다.
2. **Workspace Lock & Secrets Encryption** 부분을 찾습니다.
3. 말줄임표(...) 아이콘을 누릅니다.
4. **Enable Protection**을 고릅니다.
5. 창이 뜨면 암호 문구를 넣고, 한 번 더 넣어 확인합니다.

## 잠금이 켜지면 달라지는 것

| 항목 | 동작 |
|---|---|
| 잠기는 시점 | 작업 공간은 세션이 끝날 때마다 잠깁니다 |
| 사용 제한 | 작업 공간의 잠금을 풀기 전에는 Msty Studio를 쓸 수 없습니다 |
| 적용 범위 | 잠금은 작업 공간별로 적용됩니다. 전체에 한 번에 걸리는 것이 아닙니다 |
| 작업 공간 전환 | 현재 작업 공간이 잠겨 있으면, 풀기 전에는 다른 작업 공간으로 바꿀 수 없습니다 |

마지막 줄은 놓치기 쉽습니다. 작업 공간 A만 잠갔더라도, 마지막으로 쓰던 공간이 A라면 앱을 열 때 A의 암호 문구를 넣어야 다른 공간으로 갈 수 있습니다.

## 암호 문구 바꾸기와 잠금 끄기

- **암호 문구 교체**: 언제든 직접 바꿀 수 있습니다.
- **잠금 끄기**: 마음이 바뀌면 보호를 끌 수 있습니다.

두 작업 모두 같은 설정 부분에서 합니다. 문서에 메뉴 이름까지는 적혀 있지 않으므로, **Workspace Lock & Secrets Encryption**의 말줄임표 메뉴에서 해당 항목을 찾으세요. 당연히 둘 다 현재 암호 문구를 알고 있어야 할 수 있습니다.

## 복사와 가져오기에서의 동작

작업 공간을 복사하거나 옮길 때 잠금이 어떻게 따라가는지 알아 두어야 합니다.

| 상황 | 결과 |
|---|---|
| 잠금이 켜진 작업 공간의 설정을 복사해 새 작업 공간을 만든다 | 새 작업 공간에도 잠금이 들어가며, 같은 암호 문구를 씁니다 |
| 잠긴 작업 공간을 가져온다(import) | 가져온 뒤에 잠금을 풀어야 합니다 |

즉, 잠긴 작업 공간을 Zip으로 내보내 다른 컴퓨터로 옮겨도 암호 문구가 있어야 열 수 있습니다. 옮기기 전에 암호 문구를 확인해 두세요. 작업 공간을 내보내고 가져오는 방법은 [작업 공간 만들고 옮기기](/guide/workspace-basics/)에 있습니다.

## 좋은 암호 문구 고르기

문서는 암호 문구의 길이나 구성 조건을 적어 두지 않았습니다. 일반적인 권고를 적으면 다음과 같습니다.

- 단어 여러 개를 이은 긴 문구가 짧고 복잡한 암호보다 기억하기 쉽고 추측하기 어렵습니다.
- 다른 서비스의 비밀번호를 다시 쓰지 않습니다.
- 적어 둔 곳이 이 컴퓨터 한 대뿐이면, 컴퓨터가 고장 났을 때 함께 잃습니다. 다른 곳에도 보관합니다.

## 이 기능이 막아 주는 것과 못 막는 것

문서가 설명하는 범위는 "잠금을 풀기 전까지 민감한 설정과 API 키를 숨긴다"는 것입니다. 이를 바탕으로 구분해 봅니다.

| 막아 주는 것 | 이 기능의 범위가 아닌 것 |
|---|---|
| 자리를 비운 사이 다른 사람이 앱을 열어 대화와 키를 보는 일 | 온라인 모델로 보낸 대화가 제공업체에서 처리되는 일 |
| 잠긴 작업 공간 파일을 가져가서 여는 일 (암호 문구 없이는 열 수 없음) | 잠금을 풀어 둔 채 자리를 비운 경우 |

어떤 암호화 방식을 쓰는지, 대화 본문까지 암호화되는지, 비밀값만 암호화되는지는 문서에 구체적인 설명이 없습니다. 기능 이름이 "Secrets Encryption"이므로 비밀값 암호화가 중심이라고 볼 수 있지만, 강한 보안 요구가 있는 조직이라면 Msty에 직접 확인하는 것이 좋습니다. 조직 차원의 통제는 [보안과 거버넌스](/guide/security-governance/)에서 다룹니다.

## 관련 기능

- 대화를 아예 기록에 남기지 않으려면 Vapor 모드를 씁니다. [작업 모드](/guide/settings-modes/)를 보세요.
- API 키를 변수로 관리하려면 [환경과 변수](/guide/workspace-environments/)를 보세요.

## 켜기 전 점검표

1. 암호 문구를 정하고 안전한 곳 두 군데 이상에 적어 두었는가.
2. 데이터를 백업했는가.
3. 이 기능이 실험 기능이라는 점을 받아들일 수 있는가.
4. 작업 공간이 여러 개라면, 어느 것을 잠글지 정했는가.
5. 다른 컴퓨터로 옮길 계획이 있다면, 그곳에서도 암호 문구를 쓸 수 있는가.
