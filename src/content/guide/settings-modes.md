## 모드란

모드(Modes)는 하려는 일에 맞춰 Msty Studio의 화면이나 동작을 바꾸는 기능입니다. 공식 문서는 세 가지 모드를 소개합니다.

| 모드 | 한 줄 요약 |
|---|---|
| Vapor | 대화를 기록에 남기지 않습니다 |
| Focus | 화면에서 불필요한 요소를 숨깁니다 |
| Zen | Focus에서 입력 칸까지 숨깁니다 |

요금 페이지의 비교표에서 "Vapor, Focus, and Zen Modes"는 Free를 포함한 모든 요금제에 제공으로 표시되어 있습니다.

## 모드 켜는 곳

**Settings > General > Mode**에서 고릅니다.

Command Palette로도 바꿀 수 있습니다. `Cmd/Ctrl + K`를 누르고 모드 이름을 입력합니다. 문서에 따르면 Command Palette의 설정 명령으로 Theme, Mode, 분할 너비, 강조색, 기본색을 빠르게 바꿀 수 있습니다. 모드 전환 전용 단축키는 문서에 나와 있지 않습니다.

## Vapor 모드

### 하는 일

Vapor 모드에서 나눈 대화는 Msty Studio의 대화 기록에 저장되지 않습니다. 모드를 끄거나 다른 화면으로 이동하면 대화가 사라집니다. 문서는 Vapor 대화가 현재 주고받는 동안만 유지된다고 설명합니다.

### 어떤 때 쓰는가

- 한 번 묻고 끝낼 질문이라 목록에 남길 필요가 없을 때
- 다른 사람이 나중에 이 컴퓨터의 대화 목록을 볼 수 있는 상황일 때
- 민감한 내용을 로컬 모델에 물어보되 기록은 남기고 싶지 않을 때

예를 들어 인사 평가 문구를 다듬을 때 로컬 모델을 고르고 Vapor 모드를 켜면, 대화가 끝난 뒤 목록에 흔적이 남지 않습니다.

### 반드시 알아야 할 한계

문서는 경고를 하나 적었습니다. 클라우드 모델을 쓰면 데이터는 여전히 그 모델의 제공업체로 전송됩니다. Vapor 모드는 이것을 막지 않습니다.

정리하면 다음과 같습니다.

| 구분 | Vapor 모드의 효과 |
|---|---|
| 내 컴퓨터의 Studio 대화 기록 | 남지 않음 |
| 온라인 모델 제공업체로의 전송 | 그대로 전송됨 |
| 제공업체 쪽의 보관과 처리 | 제공업체 정책에 따름 |

즉 Vapor는 "내 쪽에 기록을 남기지 않는 기능"이지 "밖으로 보내지 않는 기능"이 아닙니다. 내용이 밖으로 나가면 안 된다면 Vapor를 켜는 것과 함께 로컬 모델을 골라야 합니다. 로컬 모델을 받는 방법은 [첫 실행과 모델 받기](/guide/first-run-and-models/)를 보세요.

또 하나, 사라진 Vapor 대화는 되찾을 수 없습니다. 답변을 나중에 쓸 생각이라면 사라지기 전에 필요한 부분을 따로 복사해 두세요.

## Focus 모드

### 하는 일

당장 하는 일에 필요하지 않은 화면 요소를 숨깁니다. 문서가 든 숨겨지는 요소는 세 가지입니다.

- 사이드바 메뉴
- 작업 공간(Workspaces)
- 디렉터리 목록

대화 본문과 입력 칸만 남으므로 화면이 넓어집니다.

### 어떤 때 쓰는가

- 긴 답변을 읽거나 긴 글을 함께 다듬을 때
- 노트북처럼 화면이 작을 때
- 화면을 공유하면서 대화 목록을 보이고 싶지 않을 때

회의에서 화면을 띄워 놓고 모델과 초안을 다듬는다면, Focus 모드가 다른 대화 제목이 보이는 것을 막아 줍니다. 다만 이는 화면 정리 기능이지 보안 기능은 아닙니다.

## Zen 모드

### 하는 일

Focus 모드에서 한 걸음 더 나아가 대화 입력 칸까지 숨깁니다. 문서는 깊이 집중하는 작업이나 방해 없이 모델과 대화하는 용도라고 설명합니다.

### 어떤 때 쓰는가

- 이미 받은 긴 답변을 방해 없이 읽을 때
- 답변을 발표 화면처럼 띄워 둘 때

입력 칸이 숨겨진 상태에서 메시지를 어떻게 보내는지는 문서에 구체적인 설명이 없습니다. 써 보고 맞지 않으면 Focus로 돌아가면 됩니다.

## 세 모드 비교

| 항목 | Vapor | Focus | Zen |
|---|---|---|---|
| 바꾸는 것 | 대화 저장 여부 | 화면 구성 | 화면 구성 |
| 사이드바 | 그대로 | 숨김 | 숨김 |
| 입력 칸 | 그대로 | 그대로 | 숨김 |
| 대화 기록 | 남지 않음 | 남음 | 남음 |
| 온라인 모델로의 전송 | 막지 않음 | 해당 없음 | 해당 없음 |

Vapor는 동작을 바꾸고, Focus와 Zen은 모양을 바꿉니다. 성격이 다르다는 점을 기억하면 헷갈리지 않습니다.

## 원래대로 돌아가기

같은 곳(**Settings > General > Mode**) 또는 Command Palette에서 모드를 끕니다. Focus나 Zen에서 사이드바가 보이지 않아 설정을 찾기 어렵다면 `Cmd/Ctrl + ,`로 Settings를 열거나 `Cmd/Ctrl + K`로 Command Palette를 엽니다. 이 두 단축키는 [단축키와 Command Palette](/guide/settings-shortcuts-command-palette/)에 정리했습니다.

## 민감한 작업을 할 때의 조합

문서의 내용을 바탕으로, 기록과 전송을 모두 줄이는 조합을 정리했습니다.

1. 로컬 모델을 고릅니다. 내용이 기기 밖으로 나가지 않게 하는 것은 이 단계입니다.
2. Vapor 모드를 켭니다. 대화 기록이 남지 않습니다.
3. 웹 검색 같은 외부 도구를 끕니다. 도구가 외부 서비스로 데이터를 보낼 수 있기 때문입니다.
4. 필요하면 작업 공간 잠금을 함께 씁니다. [작업 공간 잠금과 비밀값 암호화](/guide/workspace-lock-encryption/)를 보세요.

데이터가 어디로 가는지에 대한 공식 설명은 [보안과 거버넌스](/guide/security-governance/)에 모았습니다.
