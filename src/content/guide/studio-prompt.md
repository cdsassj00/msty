## Prompt Studio가 하는 일

**Prompt Studio**는 프롬프트를 만들고, 정리하고, Msty 전체에서 다시 쓸 수 있게 관리하는 곳입니다.

매주 쓰는 "회의록 요약" 지시문이나 "보도자료 초안" 지시문을 메모장에서 복사해 붙이고 있다면, 이를 Prompt Studio에 저장해 두고 불러 쓰는 편이 편합니다. 프롬프트에 빈칸(변수)을 넣어 두면 부서명이나 날짜만 바꿔 가며 같은 프롬프트를 재사용할 수 있습니다.

## 준비된 프롬프트 가져오기

### Discover 탭

**Discover** 탭에는 바로 쓸 수 있는 프롬프트 목록이 있습니다. 다음 기능을 제공합니다.

- 프롬프트의 제목, 본문, 태그로 검색합니다.
- **Available**, **Installed**, **All**로 걸러 봅니다.
- 알파벳순으로 정렬합니다.
- 설치하기 전에 프롬프트를 열어 전체 본문과 태그를 확인합니다.
- 프롬프트 하나를 내 라이브러리에 바로 설치합니다.
- 여러 개를 선택해 한 번에 설치합니다. 이 경우 **Misc** 폴더에 들어갑니다.
- 여러 개를 설치할 때는 진행 상황이 표시되고, 다 끝나기 전에 중단할 수 있습니다.

### 기본 프롬프트 모음

1. **New Prompt** 옆의 아래쪽 화살표를 누릅니다.
2. **Import Default Prompts**를 고릅니다.

이 메뉴는 앱에 포함된 기본 모음을 한꺼번에 불러옵니다. 더 큰 목록에서 필요한 것만 골라 설치하려면 **Discover**를 씁니다.

## 새 프롬프트 만들기

**New Prompt**를 누르고 **Title**(제목)과 프롬프트 본문을 입력합니다.

**New Prompt** 옆의 아래쪽 화살표에서는 다음 방법도 쓸 수 있습니다.

- 클립보드에서 프롬프트 가져오기
- 프롬프트가 하나 이상 담긴 JSON 파일 올리기

## 폴더로 정리하기

**New Prompt** 옆의 아래쪽 화살표, 또는 기존 폴더 옆의 말줄임표(⋯) 메뉴에서 폴더를 만듭니다.

- 최상위 폴더
- 하위 폴더

프롬프트를 폴더로 옮겨 두면 찾기 쉽습니다.

## AI Assistant

프롬프트를 새로 쓰거나 다듬는 일을 도와주는 기능입니다. 공식 문서에서 이 항목에는 **Aurum Perk** 표시가 붙어 있습니다.

Prompt Studio 창 아래쪽의 **AI Assistant** 버튼으로 켭니다. 할 수 있는 일은 세 가지입니다.

- 새 프롬프트 만들기
- 기존 프롬프트 개선하기
- 태그 제안받기

새 프롬프트를 만드는 순서는 다음과 같습니다.

1. AI Assistant가 사용할 모델을 고릅니다.
2. 용도에 맞는 카테고리를 고릅니다.
3. 출력 스타일을 간결하게 할지 자세하게 할지 고릅니다.
4. 변수와 태그를 몇 개 넣을지 정합니다.
5. **Generate Prompt**를 누릅니다.
6. 결과를 검토하고 고친 뒤 **Apply Prompt**를 눌러 라이브러리에 추가합니다.

변수는 프롬프트를 쓸 때 채워 넣는 빈칸입니다. 변수를 넣어 두면 하나의 프롬프트를 여러 상황에 다시 쓸 수 있습니다.

## Sandbox에서 테스트하기

프롬프트 버전을 시험하고 비교하는 공간입니다. 공식 문서에서 이 항목에도 **Aurum Perk** 표시가 붙어 있습니다.

프롬프트를 열고 창 위쪽의 **Sandbox** 버튼을 누릅니다. 설정 항목은 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| **Select Model** | 테스트에 쓸 모델 |
| **Select Prompt Version** | 테스트할 버전 |
| **Add System Prompt** (선택) | 추가 맥락이나 지시 |
| **Edit Prompt** (선택) | 테스트용 임시 수정. 저장된 버전은 바뀌지 않습니다 |
| **Set Variable Values** (선택) | **Run** 옆의 별표(\*) 아이콘을 눌러 변수 값을 넣습니다. **Resolved**를 누르면 값이 채워진 프롬프트를 볼 수 있습니다 |

**Run**을 누르면 모델의 응답이 나옵니다. 출력에 있는 디스크 아이콘을 누르면 테스트 결과가 저장됩니다. 저장한 결과는 오른쪽에 나타나며, 생성된 프롬프트와 당시 설정을 다시 볼 수 있습니다.

### Arena

여러 버전을 맞붙여 비교하는 기능입니다. 비교할 버전에 체크하고 **Start Arena**를 누릅니다. 버전들을 여러 번 테스트한 뒤 가장 성적이 좋은 버전을 승자로 표시합니다. 판정 기준이 무엇인지는 공식 문서에 설명이 없습니다.

## Versions

프롬프트 하나에 여러 버전을 저장해 변경 이력을 추적합니다. 공식 문서에서 이 항목에도 **Aurum Perk** 표시가 붙어 있습니다.

버전 옆의 별 아이콘을 누르면 그 버전이 기본값이 됩니다. 프롬프트를 적용할 때 기본 버전이 사용됩니다.
