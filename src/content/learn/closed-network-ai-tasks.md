## 기준으로 삼은 자료

AI 업무 활용 교육과정 보드는 역량 모듈마다 망 환경을 세 가지로 표시합니다.

| 표시 | 뜻 |
|---|---|
| 외부망 필요 | 인터넷이 되는 PC에서만 할 수 있습니다 |
| 폐쇄망 대안 있음 | 외부망과 폐쇄망 어느 쪽에서도 할 수 있습니다 |
| 반입 후 사용 | 외부망에서 설치 파일과 모델을 받아 폐쇄망으로 옮긴 뒤 씁니다 |

이 글을 쓰면서 확인한 보드에는 모듈이 83개 있고, 외부망 필요가 31개, 폐쇄망 대안 있음이 47개, 반입 후 사용이 5개입니다. 절반 이상은 인터넷이 없어도 할 수 있다는 뜻입니다.

## 방법별로 보면

보드는 AI를 쓰는 방법을 대화형, 위임형, 제작형, 구축형으로 나눕니다. 망 환경 표시를 방법별로 세면 다음과 같습니다.

| 방법 | 외부망 필요 | 폐쇄망에서도 됨 | 반입 후 사용 |
|---|---|---|---|
| 대화형 (AI 대화창에서 묻기) | 13 | 16 | 1 |
| 위임형 (전용 AI 서비스에 맡기기) | 14 | 0 | 0 |
| 제작형 (AI가 짠 코드 실행) | 1 | 20 | 1 |
| 구축형 (시스템 직접 만들기) | 3 | 11 | 3 |

눈에 띄는 것은 위임형입니다. 14개가 모두 외부망 전용입니다. 문서를 올리면 그 안에서만 답하는 전용 서비스, 회의 녹음 전사 서비스, 슬라이드 생성 서비스, 브라우저를 조작하는 에이전트가 여기에 듭니다. 반대로 제작형은 22개 가운데 20개가 폐쇄망에서도 됩니다.

보드의 설계 기록은 이 점을 이렇게 설명합니다. 폐쇄망에서 위임형이 비는 것은 당연하며, 폐쇄망 기관은 대화형에서 제작형으로 건너가고, 전산 담당자가 구축형으로 에이전트를 만들어 직원이 그 위에서 쓰는 구조가 됩니다.

## 폐쇄망에서 그대로 되는 일

로컬 대화창이나 기관 LLM 대화창만 있으면 되는 일입니다.

| 업무 영역 | 할 수 있는 일 |
|---|---|
| 공통 기반 | 텍스트에서 정보 뽑기·조합·변환, 프롬프트를 AI에게 설계시키기, 결과 검증과 환각 점검, 업무를 단계로 나눠 문제 정의하기 |
| 문서 | 기안·보고·회의록 초안과 요약, 문체 변환, 맞춤법·쉬운 말·번역, 대상별 글쓰기, 부서 양식을 넣은 문서 도우미 |
| 콘텐츠 | 기획안, 카드뉴스 문안, 영상 대본, 슬라이드 개요 |
| 데이터 | 시트 구조를 설명하고 수식·정제·피벗 방법 묻기, 통계표를 읽고 보고 문장 쓰기 |
| 업무처리 | 업무 절차서·체크리스트·인수인계서 정리 |

AI가 짜 준 코드를 실행하는 일도 대부분 됩니다. 문서 파일 일괄 처리, HWPX 양식 자동 채우기, 문서 비교·검수 도구, 오프라인 문서 검색 도구, Excel 자동화, Python 데이터 정제, 대량 텍스트 분류, 브라우저에서 돌아가는 HTML 도구, PC 반복작업 자동화가 여기에 듭니다. Office VBA는 따로 설치할 것이 없어 폐쇄망에서 바로 씁니다.

다만 같은 모듈 안에서도 일부 실습은 외부망이 필요하다고 표시되어 있습니다. 예를 들어 사진·스캔·그래프 이미지를 읽고 설명하게 하기, 대화 중에 이미지를 생성하고 고치기가 그렇습니다.

## 반입해야 쓸 수 있는 일

다섯 가지는 외부망에서 준비해 옮겨야 합니다.

| 일 | 반입할 것 |
|---|---|
| 로컬 AI 대화창 | 대화창 프로그램 설치 파일, 언어 모델 파일 |
| 로컬 이미지 생성과 일괄 편집 | 이미지 생성 모델, 실행 도구 |
| 기관 문서 질의응답 (RAG) | 언어 모델, 임베딩 모델 |
| 폐쇄망 회의록·문서 요약 | 전사 모델(Whisper), 언어 모델 |
| 업무 에이전트 | 오픈소스 코딩 하네스, 언어 모델 또는 기관 LLM 연결 |

반입 절차와 준비물은 [로컬 AI 설치 전에 전산·보안 담당자에게 물어볼 것](/learn/before-install-ask-it-security/)에서 다룹니다.

## 폐쇄망에서 안 되는 일

외부망 필요로 표시된 31개는 두 부류입니다.

**대안이 달려 있는 것.** 22개에는 폐쇄망에서 대신 쓸 모듈이 붙어 있습니다. 회의 녹음 전사 서비스 대신 로컬 전사 모델을 쓰는 식입니다. 목록은 [외부 전용 AI 서비스를 폐쇄망에서 대신하는 방법](/learn/closed-network-alternatives/)에 표로 정리했습니다.

**대안이 달려 있지 않은 것.** 아래 일은 보드에 대안 표시가 없습니다. 성격상 인터넷 자체가 필요한 일이 많습니다.

| 일 | 인터넷이 필요한 이유 |
|---|---|
| AI 검색·리서치와 출처 확인 | 웹에서 최신 자료를 찾아야 합니다 |
| 법령·규정 검색과 해석 보조 | 온라인 법령 정보와 외부 AI 서비스를 씁니다 |
| 대화창에서 이미지 생성·편집 | 외부 서비스의 이미지 생성 기능을 씁니다 |
| 사진·스캔 자료에서 데이터 뽑기 | 외부 서비스의 이미지 읽기 기능을 씁니다 |
| 대화만으로 작은 업무 도구 바로 만들기 | 외부 서비스의 캔버스·아티팩트 기능을 씁니다 |
| 메일·일정·메신저 내용 정리 | 외부 대화 서비스에 내용을 옮겨야 합니다 |
| 코딩에이전트 설치와 작업 지시 | 외부 서비스에 연결해 동작합니다 |
| 웹 서비스 배포, 콘텐츠 자동 배포 | 외부 호스팅 서비스에 올립니다 |

표시가 없다고 방법이 전혀 없다는 뜻은 아닙니다. 예를 들어 사진 속 글자는 기기 안에서 도는 글자 인식으로 읽을 수 있고, [실습](/lab/)의 "사진 속 글자 읽기"로 확인해 볼 수 있습니다. 웹 배포도 보드는 내부망에서 도는 로컬 서버 방식을 함께 언급합니다. 그래도 최신 정보를 웹에서 찾는 일은 폐쇄망 안에서 대신할 수 없습니다.

## 정리

- 요약, 초안, 교정, 번역, 표 정리처럼 주어진 글을 다루는 일은 폐쇄망에서도 됩니다.
- 편리한 전용 서비스는 쓸 수 없습니다. 같은 결과가 필요하면 코드를 실행하거나 직접 구축해야 합니다.
- 웹에서 새 정보를 찾는 일은 외부망 PC에서 따로 합니다.

실제 업무에 적용한 예는 [로컬 모델로 문서 업무 하기](/learn/local-ai-document-work/)부터 이어집니다.
