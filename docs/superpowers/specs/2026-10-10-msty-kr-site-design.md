# msty.kr 로컬 우선 AI 한국어 가이드 사이트 — 설계서

- 작성일: 2026-10-10
- 저장소: `cdsassj00/msty` (public, 현재 비어 있음)
- 작업 폴더: `C:\Users\value\Desktop\MSTY`

## 1. 목적

`msty.kr`을 "보안 걱정 없이 AI를 쓰는 방법"을 찾는 한국어 사용자의 입구로 만든다.

- Msty를 소개하고 공식 다운로드로 안내한다.
- Ollama, Gemma, 임베딩 등 로컬 우선 AI의 소식과 학습 자료를 쌓는다.
- 한국에서 Msty로 보낸 방문 규모를 숫자로 남겨, 이후 Msty 본사와 다시 이야기할 근거로 쓴다.
- 사이트 가이드를 책 「보안걱정없이 LLM과 AI를 사용할 수 있는 가장 쉬운 방법」 개정판(V3)의 원고로 겸한다.

### 독자

1. 책을 사고 `msty.kr`로 들어오는 사람 (책 16쪽이 다운로드 위치로 `Msty.kr`을 안내한다).
2. "로컬 LLM", "보안 AI", "폐쇄망 AI"를 검색하는 직장인·공공기관 담당자.
3. Msty 본사 (영문 요약 페이지는 후속 단계).

### 성공 기준

- `msty.kr` 접속 후 두 번의 클릭 안에 Msty 공식 다운로드 페이지에 도달한다.
- 전환 후 한 달간 `/download` 조회 수와 유입 검색어를 Cloudflare Web Analytics에서 확인할 수 있다.
- 새 글 한 편을 올리는 일이 마크다운 파일 하나 추가와 `git push`로 끝난다.

## 2. 범위

이 설계서는 1차 구현(MVP와 도메인 전환)만 다룬다.

| 포함 | 제외 (후속 설계서) |
|---|---|
| 사이트 뼈대, 디자인, 7개 메뉴 | 위키 선별 내보내기 스크립트 |
| MVP 콘텐츠 (4절 목록) | 브라우저 데모를 사이트 안으로 복사 |
| Cloudflare 배포, 도메인 전환 | 뉴스레터, 영문 Korea 페이지 |
| RSS·JSON 피드, 방문 분석 | cdsa.kr·shinsungjin.com 쪽 연동 작업 |
| | 책 V3 편집·출간 |

기존 `msty.kr` 빌더 사이트에는 옮길 강의·게시글이 없으므로 콘텐츠 이전은 하지 않는다.

## 3. 기술 구성

| 항목 | 결정 | 이유 |
|---|---|---|
| 프레임워크 | Astro (정적 출력) | 글 하나가 파일 하나. 자바스크립트 없이도 페이지가 뜬다 |
| 콘텐츠 | Astro 콘텐츠 컬렉션, 마크다운 | 책 원고로 재사용하기 쉽다 |
| 스타일 | ssjsite `design-tokens.css`를 순수 CSS로 사용 | Tailwind 의존을 줄인다. VibeStack 보드와 같은 톤 |
| 폰트 | Pretendard Variable (jsDelivr) | ssjsite 규칙 |
| 호스팅 | Cloudflare Workers 정적 자산, GitHub 저장소 연동 | Cloudflare의 현재 Astro 안내 방식. `main` push 시 자동 배포. DNS와 한곳에서 관리 |
| 분석 | Cloudflare Web Analytics | 쿠키 없음. 동의 배너가 필요 없다 |
| 검색 | 없음 (MVP) | 글이 30편을 넘으면 검토한다 |

2026-10-10에 Cloudflare 공식 Astro 안내를 확인해 Workers 정적 자산(`wrangler.jsonc`의 `assets`)으로 정했다.

### 디렉터리

```
src/
  content/
    guide/     Msty 가이드 (책의 장 순서)
    learn/     로컬 AI 학습
    news/      소식
  content.config.ts   컬렉션 스키마
  layouts/     Base.astro, Article.astro
  components/  Header, Footer, Card, Chip, DownloadCta, Disclosure
  pages/       index, download, guide/, learn/, news/, lab/, book, about, 404
  styles/      tokens.css (ssjsite), site.css
public/        favicon, og 이미지, _redirects
```

### 글 머리말(frontmatter) 스키마

모든 컬렉션 공통:

| 필드 | 형식 | 필수 | 설명 |
|---|---|---|---|
| `title` | 문자열 | 예 | 제목 |
| `description` | 문자열 | 예 | 목록과 검색 결과에 쓰는 한두 문장 |
| `date` | 날짜 | 예 | 발행일 |
| `updated` | 날짜 | 아니오 | 마지막 수정일 |
| `tags` | 문자열 배열 | 아니오 | 칩으로 표시 |
| `draft` | 불리언 | 아니오 | 참이면 빌드에서 제외 |

컬렉션별 추가:

- `guide`: `order`(숫자, 책의 장 순서), `verified`(날짜, 현재 앱 화면과 대조한 날).
- 실습 카드는 컬렉션이 아니라 `src/data/lab.json`에 둔다 (`name`, `url`, `desc`). 데모를 사이트 안으로 옮기는 후속 단계에서 컬렉션으로 바꾼다.

| `/download` | 운영체제별 안내와 Msty 공식 Studio 페이지(`https://msty.ai/products/studio/`)로 가는 버튼. 설치 가이드로 연결 |

### MVP에 넣는 글

가이드 5편:

1. Msty란 무엇인가 — 로컬 우선 AI와 제품 4종 (Studio, Go, Nexus, Stack)
2. Windows에 설치하기
3. Mac에 설치하기
4. 첫 실행과 모델 받기
5. Ollama 모델을 Msty에 연결하기

학습 2편:

1. Ollama 처음 시작하기
2. 내 PC 사양으로 돌릴 수 있는 모델 고르기

소식 1편: 사이트 개편 안내와 Msty 제품 체계 변화 요약.

실습 카드 8개 (VibeStack 보드의 데모로 링크): `44-local-gemma`, `57-webllm`, `58-chrome-builtin-ai`, `55-whisper`, `56-kokoro-tts`, `53-doc-search`, `54-ocr`, `42-text-ai`. 배포된 주소는 구현 때 보드에서 직접 열어 확인한다.

### 모델 링크 페이지 (`/models`)

로컬 모델을 찾고, 비교하고, 내 PC에서 도는지 확인하는 외부 사이트를 한 페이지에 모은다. 원고는 `docs/content-drafts/model-links.md`이며 9개 묶음, 약 60개 링크다.

- 묶음: 모델 찾기와 받기, 전체 모델 목록, 성능 리더보드, 한국어 성능, 용도별 리더보드, 내 PC에서 돌아가는지, 속도, 실행 도구, 소식과 커뮤니티.
- 데이터는 `src/data/model-links.json` 한 파일에 둔다. 항목은 `group`, `name`, `url`, `desc`, `checked`(접속 확인일), `note`(선택)를 가진다.
- 화면은 묶음별 `.panel` 카드 목록과 상단의 묶음 바로가기 칩으로 구성한다. 링크는 새 탭으로 연다.
- 순위와 점수는 옮겨 적지 않는다. 한 줄 설명과 링크만 둔다.
- 배포 전 링크 검사에 이 파일의 주소를 포함한다. 응답이 없는 항목은 내리고 원고의 "제외한 것"에 적는다.
- 홈과 "내 PC 사양으로 돌릴 수 있는 모델 고르기" 글에서 이 페이지로 연결한다.

### 콘텐츠 작성 규칙

- Msty 화면·메뉴·요금 설명은 Msty 공식 문서와 현재 앱을 확인하고 쓴다. 2024년 책 내용을 그대로 옮기지 않는다. 확인한 날짜를 `verified`에 적는다.
- 확인하지 못한 기능은 쓰지 않는다.
- 스크린샷은 운영자가 직접 캡처한 것만 쓴다. MVP에서 없는 글은 글만으로 낸다.
- 문체는 합니다체, 비개발자 눈높이.

## 5. 디자인

ssjsite 디자인 시스템을 그대로 따른다.

- 배경 순수 블랙, 표면은 iOS 그레이 계단, 액센트 iOS 블루, 포인트 골드.
- 프로스티드 고정 헤더, 풀블리드 히어로, `overline-label`로 시작하는 섹션 스택, 푸터.
- 모션은 스크롤 페이드업과 히어로 제목 라인마스크만 쓴다. `prefers-reduced-motion`에서 모두 끈다.
- 글 본문은 최대 폭 약 720px, `word-break: keep-all`.
- 목록은 `.panel` 카드, 분류는 `.chip`.

Msty의 로고와 브랜드 색은 쓰지 않는다. 제품은 이름과 글로만 소개한다.

## 6. 비공식 표기와 공개 원칙

현재 Msty와 맺은 MOU가 없으므로 다음을 지킨다.

- 푸터와 `/about`에 "이 사이트는 한국데이터사이언티스트협회가 운영하는 비공식 한국어 가이드이며 Msty 본사와 제휴 관계가 아닙니다"를 적는다.
- 설치 파일을 사이트에 올리지 않는다. 공식 다운로드 페이지로만 링크한다.
- Msty 사이트의 문구와 이미지를 복사하지 않는다.
- 연락처는 이메일(`sjshin@cdsa.or.kr`)만 공개한다. 전화번호는 싣지 않는다.
- 개인 위키 내용은 자동으로 연동하지 않는다. MVP 글은 모두 새로 쓴다.

- 표시 정보: 제목, 저자(신성진·김태유), 펴낸곳(한국데이터사이언티스트협회), 발행일 2024-12-06, 가격 5,000원.
- 구매 버튼: 판매 링크를 받으면 연결한다. 받기 전에는 "구매 문의" 메일 버튼을 둔다.
- "책 이후 달라진 점": 제품 체계 변화와 다운로드 위치를 정리하고, 각 장에 대응하는 최신 가이드 글로 연결한다.
- 책 PDF 파일은 사이트에 올리지 않는다.

## 8. 도메인 전환

순서:

1. Cloudflare가 주는 임시 주소(`*.workers.dev`)에서 검수한다.
2. `msty.kr`과 `msty.co.kr`의 현재 네임서버, 등록 기관, MX 레코드를 조회해 기록한다. 메일을 쓰고 있으면 MX를 그대로 옮긴다.
3. `msty.kr`을 Cloudflare에 연결한다. `www.msty.kr`은 `msty.kr`로 301.
4. `msty.co.kr`과 `www.msty.co.kr`은 `msty.kr`의 같은 경로로 301.
5. 기존 빌더의 `/channels/*` 경로는 `/`로 301 (`public/_redirects`).
6. 전환을 확인한 뒤 기존 빌더 구독을 해지한다. 해지는 운영자가 직접 한다.

DNS 변경과 빌더 해지는 되돌리기 어려우므로, 실행 직전에 운영자 확인을 받는다.

## 9. 방문 분석

- Cloudflare Web Analytics로 페이지별 조회 수, 유입 경로, 검색어를 본다.
- Msty로 보낸 규모의 지표는 `/download` 조회 수로 잡는다.
- 공식 사이트로 나가는 버튼의 클릭 수는 MVP에서 세지 않는다. 필요해지면 후속 단계에서 클릭 집계용 Worker를 추가한다.

## 10. 다른 사이트와의 연결

- 푸터와 `/about`에 `cdsa.kr`, `shinsungjin.com` 링크를 둔다.
- `/feed.json`은 글마다 `title`, `url`, `date`, `description`, `tags`, `collection`을 담는다. 두 사이트가 나중에 이 피드로 최신 글을 가져갈 수 있다.

## 11. 오류 처리

- 없는 주소는 `/404`로 보내고 홈·다운로드·가이드 링크를 보여 준다.
- 스키마에 맞지 않는 머리말은 빌드를 실패시켜 배포를 막는다.
- 외부 데모나 공식 다운로드 주소가 바뀌면 깨진 링크가 된다. 배포 전 링크 검사로 잡는다.

## 12. 검증

- `astro build`가 경고 없이 끝난다.
- 내부·외부 링크 검사를 통과한다.
- 모바일 폭(375px)과 데스크톱에서 모든 페이지를 눈으로 확인한다. 가로 스크롤이 없어야 한다.
- Lighthouse 성능·접근성 90점 이상.
- 모션 줄이기 설정에서 애니메이션이 꺼진다.
- `/rss.xml`과 `/feed.json`이 유효한 형식이다.
- 전환 후 `msty.co.kr`, `www`, `/channels/...` 리다이렉트가 동작한다.

## 13. 후속 단계 (이 설계서 밖)

1. 위키 선별 내보내기: 위키 페이지 머리말에 공개 표시가 있는 것만 `learn`·`lab`으로 변환.
2. 로컬 AI 데모를 사이트 안으로 복사 (모델·라이브러리 용량 확인 후).
3. 주 1회 소식 발행 흐름.
4. 영문 Korea 요약 페이지, 뉴스레터.
5. 가이드 글을 묶어 책 V3 편집.
